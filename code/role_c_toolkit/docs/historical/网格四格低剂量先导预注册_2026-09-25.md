# 网格四格低剂量先导预注册

登记时间：2026-09-25；在低剂量数据运行前建立。用途为游戏智能体架构诊断。

## 问题与假设

高剂量四格实验中，planner、executor、both 三个注入格在 20 个 seed 全部落到效用下限 0.20，无法区分单层损失与跨层交互。本先导检查剂量 0.25 是否能让至少部分干预臂离开下限，同时保持规划器与执行器故障确实触发且可重放。

## 固定设计

- 新 seed：120–124；五个配对 seed，仅作为探索性先导，不纳入 seed 100–119 的确认性统计。
- 场景与其余运行配置、代码版本、评分方式沿用 `grid-factorial-p1-e1-s100-119-v1`。
- 四格依次为 clean `(0,0)`、planner `(.25,0)`、executor `(0,.25)`、both `(.25,.25)`。
- 每格执行一次原始运行及自身精确重放；记录效用、规划器/执行器注入事件数与重放精确性。
- 主要诊断量：每个注入格得分是否高于 0.20 下限，以及配对 seed 下 `ΔP=V(clean)-V(planner)`、`ΔE=V(clean)-V(executor)`、`ΔI=V(both)-V(planner)-V(executor)+V(clean)`。
- 质量门：五 seed 四格完整；所有重放精确；planner-only 只触发规划器事件、executor-only 只触发执行器事件，both 同时有两类事件；独立审计无完整性错误。

## 解释与后续决策规则

这是剂量选择的先导，不检验理论定律。若至少 3/5 seed 的 planner 或 executor 单层臂高于 0.20，且注入/重放质量门通过，则 0.25 可作为后续独立确认批次的候选剂量；若两个单层臂中任一在至少 4/5 seed 仍等于下限，则下一先导应测试 0.10。任何数据驱动选出的剂量需在新的确认 seed 集上冻结后检验，不与本先导合并为确认性证据。交互项仅在两单层臂和联合臂有足够非下限变化时描述；否则标注为受评分地板限制、不可分辨。
