# Grid 五类故障中等难度冒烟分析

日期：2026-09-25。对应运行前预注册：`网格五类故障中等难度复验预注册_2026-09-25.md`。

## 数据与审计

目录 `artifacts/grid-fault-five-case-medium-s100-smoke-v1/` 共 21 个条件：无故障参考 1 格，加五类故障分别在 dose 0、0.25、0.5、1.0 下的 20 格。每格均有原始 episode 和基于自身已记录决策的固定决策重放。批次标记 `run_and_replay_valid=true`；独立审计 `artifacts/grid-fault-five-case-medium-s100-smoke-v1-audit/audit.json` 的 `errors=[]`，每个剂量格均有非零剂量事件日志与精确重放。

## 结果

以下得分和事件数按 dose 0 / 0.25 / 0.5 / 1.0 排列：

| 注入类型 | 得分 | 已记录注入事件 | 严格单调下降 |
|---|---|---|---|
| 规划器错误目标 | 1.000 / 1.000 / 1.000 / 0.200 | 0 / 2 / 2 / 8 | 否 |
| 接口字段裁剪 | 1.000 / 1.000 / 1.000 / 0.200 | 0 / 8 / 18 / 21 | 否 |
| 接口目标丢失 | 1.000 / 1.000 / 1.000 / 0.200 | 0 / 5 / 21 / 24 | 否 |
| 执行器改选最近接触 | 1.000 / 1.000 / 1.000 / 1.000 | 0 / 1 / 4 / 40 | 否 |
| 动作保持 | 1.000 / 0.933 / 1.000 / 0.200 | 0 / 94 / 82 / 108 | 否 |

虽然难度降为 medium，seed100 的无故障参考仍是效用满分 1.0；0.25 与 0.5 对四种注入没有得分影响，动作保持还非单调，最近接触注入在所有剂量都不影响效用。因此此条件仍缺少评分 headroom/分辨率，增加到 20 seeds 不会补救单 seed 已揭示的尺度问题。按预注册停止，不扩成 medium 主批次，也不改变评分或事后重定义剂量。

## 解释边界与下一步

本结果证明注入点可触发、事件可审计且重放精确；不证明归因分类恢复率、因果剂量单调、规划器/执行器参考质量或论文 A10 验收。若要继续 Grid 归因，应先选择能让纯系统基线既不贴近 1.0 天花板也不贴近 0.2 地板的预先固定场景/种子总体，并检验独立参考规划器和执行器；不能只挑这个 seed 上看起来更合意的案例。

该 runner 测试的是 rule planner + heuristic executor，不是 LLM 混合架构。Grid 中针对混合架构的正式 B_if 与归因注入仍需实际接入 hybrid agent，并先核验 LLM 服务可用性与输出可靠性。
