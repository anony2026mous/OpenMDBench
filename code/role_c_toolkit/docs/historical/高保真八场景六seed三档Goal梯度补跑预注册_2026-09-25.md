# 高保真八场景六 seed 三档 Goal 梯度补跑预注册

登记时间：2026-09-25，在运行前。用途是游戏智能体场景中的接口梯度诊断。

## 目的

为 IE-01 至 IE-08 的每个场景补齐 weak/medium/strong Goal 粒度操纵的配对轨迹，并取得跨 seed 重复。此前 seed 100 的 IE-01、IE-04 操纵检查和 IE05–IE08 场景轨迹只有单 seed，无法测 seed 间方差。本批原始/重放数据将支持独立审计、决策接口行为检查及后续经校准的 B_if 分析。

## 固定设计

- 场景：IE-01-SINGLE-TARGET、IE-02-DUAL-THREAT、IE-03-SURFACE-RAID、IE-04-COMBINED-ARMS、IE-05-MULTI-AXIS、IE-06-DECOY-MIXED、IE-07-CROSS-DOMAIN、MD-AD-006-ISLAND-STRIKE。
- 种子：101–106，共 6 个；每个场景和每个 seed 都跑 weak、medium、strong。
- 每个场景×seed×Goal 档先跑原始轨迹，再从该原始轨迹执行同条件固定决策重放。
- 运行参数：最大 1800 tick，plan interval 10，单步墙钟超时 300 秒，世界检查点间隔 50 tick；要求自然终局。
- 唯一接口干预：引擎 `AgentV2.goal_granularity -> GoalCommand.to_granularity`。引擎源码不修改。
- 完整性门：三档首批 Goal 字段按 weak⊂medium⊂strong 嵌套；原始/重放达到同一自然终局且逐步指纹、决策精确一致；独立审计无错误；启动和结束时记录工作区引擎版本 manifest 哈希。
- 统计单位为 seed。Goal 字段嵌套与动作轨迹差异仅作操纵检查；B_if 梯度需另过混合测度估计器校准、有效样本支持、时间依赖和 seed 不确定性门禁。

## 资源与解释规则

全批 144 个原始/重放 episode；按已有全时段文件大小估计需几十 GB。每完成一个场景检查磁盘；若剩余空间低于 25 GB，则停止在完整场景边界并保留已有数据，不破坏已完成报告。未达到完整性门的场景×seed×档不计入梯度样本。六个 seed 用于阶段性梯度诊断，不能替代跨版本复验，也不自行保证 D3 通过。
