# Grid 原生离散位置通道 B_if 重分析方案

方案锁定时间：2026-09-25。本文件在该**新投影估计**运行前锁定；输入 episode 是已完成的历史 grid 20-seed campaign，因此这是预先锁定口径的既有数据重分析，不是前瞻性预注册实验。

## 目标与适用范围

补充测量 OpenMDBench §5.2 的直接 `I(G_t; S_{t+1})` 关联量。Grid 世界的位置本身是有限格点、目标位置亦为名义类别，普通连续 KSG 的连续密度假设不成立。本方案用 grid 原生有限离散状态的 plug-in MI 估计一个预先定义的位置通道投影；不得称为普通 KSG，亦不替代 full structured B_if。该项用于补齐 grid 新追踪器的 per-cell、多 seed 描述并诊断历史 full-state singleton 退化。

## 固定投影

- 观测单元：每一转移、每个己方 unit，保持 unit_id 分层，不跨单位合并。
- X（接口侧）：转移前该 unit 最高 priority 的 active Goal；同优先级沿用 trace 列表首项。编码为 `(goal_type, target_position_present, target_x, target_y)`；无 Goal 编为独立 `no_goal` 类；Goal 无合法位置则显式区分位置缺失。不含 `task_id`、`issued_at`、unit_id 或下游行动。
- Y（执行状态侧）：同 unit 转移后的 `(alive, x, y)`；死 unit 状态作为单独名义状态。记录单位是每个 tick 的一个 Goal—状态样本对。
- quantity：每个 seed、unit 独立计算 plug-in `I(X;Y)`，单位 bit；每个 condition×unit 的主汇总为 seed-level MI 均值、样本 SD、10,000 次 paired-by-seed bootstrap percentile 95% CI。seed 是唯一重抽样单位；不同 cell 共用 seed 编号，跨 cell 差值以同 seed 配对。
- 时间错位诊断：对每 episode 将 X 作非零循环位移，取至多 31 个均匀位移的 MI 均值，报告 `observed − shifted_mean`；仅作时序对齐诊断，不作 p 值、不视为去偏估计。
- 完整性：campaign 180 个 B_if rows、种子 100–119、三 task modes、三 decision intervals 均齐全；逐一校验原始 report hash、trace hash、own-replay exact-match、配置和源清单。任何失败均停止，不静默丢行。

## 解释门禁

1. `I(X;Y)` 是有限离散投影上的 plug-in MI，非因果效应、非 bit/s、非普通 KSG。对有限样本的上偏、稀疏占用格数和 singleton fraction 必须随 cell/seed 披露。循环错位对照不能消除状态自相关或构成统计显著性检验。
2. 这批 campaign 改变 task_mode 和 planner interval，没有操纵 Goal 字段粒度；因此只能比较被观察的 cell 和报 multi-seed 方差，**不验收 Goal-tier D3 梯度**。
3. planner=rule、executor=heuristic；不属于 LLM+GOAI 混合架构数据。position projection 也不是完整 Goal→全执行状态 `B_if`。
4. 结果无论数值正负均保留，不按方向筛选 seeds，不把 singleton 严重的 cell 转为 null/0 后删掉；若可用支撑不足，明确报告不确定性。
