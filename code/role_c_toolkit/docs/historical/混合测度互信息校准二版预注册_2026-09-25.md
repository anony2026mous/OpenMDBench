# 混合测度互信息校准二版预注册

登记时间：2026-09-25，第二版合成校准运行前。第一版 `mixed-measure-calibration-v1` 保留原样；它的固定 k=5 结果未达到预先设置的误差门槛。

## 估计器与目的

估计器按 Gao、Kannan、Oh 与 Viswanath（NeurIPS 2017）提出的混合离散/连续概率测度 k-NN 方法实现，能把完全重复的联合观测作为原子点质量处理。该方法的一致性条件要求 k 随样本量增加且相对 N 增长较慢。第二版检查按样本量增长的 k 对混合案例是否有可接受偏差，以及在高保真单单位约 1,199 个 tick 的样本规模是否有基本可用性。

## 固定设计

- 独立合成 seed 5100–5119，共 20 个；样本量 `N ∈ {500, 1199, 2000}`。
- 案例：独立高斯、相关高斯、纯离散 BSC、离散类别—连续高斯信道、高维 4D Goal/7D state 加精确原子混合、独立零膨胀点质量混合。
- k 值按 `ceil(N^0.30)`, `ceil(N^0.40)`, `ceil(N^0.50)` 生成，并逐项报告。主要校准值固定为 `ceil(N^0.40)`；不按接近真值程度事后挑 k。
- 所有估计保留负值，不加抖动，不丢弃类别/点质量，不截断负值。记录原子样本比例、联合重复点比例和非零半径边界并列情况。
- 区间以 20 个独立合成 seed 为重采样单元，bootstrap 1000 次、rng seed 0。

## 预先固定的工程门槛

在 N=1199 与 2000 的主要 k 上：独立案例绝对均值 <0.15 bits；连续相关、纯离散、离散—连续信道案例绝对偏差 <0.20 bits；高维含原子混合案例绝对偏差 <0.30 bits，且原子零半径质量比例不低于理论原子概率减 0.03。所有候选 k 的估计必须落盘。敏感性另外报告主要 k 与高/低 k 均值差，不用敏感性结果选唯一参数。

这些门槛只是进入游戏轨迹探索测量的工程校准门槛，不等于统计覆盖率证明、IID 时间序列验证、D3 验收或论文 B_if 验证。
