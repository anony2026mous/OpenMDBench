# 网格四格剂量 0.25 先导分析

对应运行：`artifacts/grid-factorial-p025-pilot-s120-124-v1/`。先导方案登记在 `网格四格低剂量先导预注册_2026-09-25.md`，在运行前写定。用途是诊断剂量，不是确认性检验。

## 质量结果

五个 seed 的四格共 20 格，原始运行和自身重放均完成。独立审计 `artifacts/grid-factorial-p025-pilot-s120-124-v1-audit/audit.json` 错误为空；规划器单层只有规划器事件、执行器单层只有执行器事件、联合格两层事件均触发，所有重放一致。

## 解释

预注册的字面筛选条件（至少 3/5 seed 的某个单层条件高于 0.20）达到，但结果推翻了“0.20 是通用分数下限”的假设：seed 121 得分为 0.167，executor 注入最高到 0.933。0.20 只能描述高剂量 20-seed 批次中的共同平台，不能作为跨剂量真实效用下限。因此不能据预注册筛选句把 0.25 直接称为已确认的归因剂量。

更关键的是，executor 注入在多个 seed 提升得分，两个层的效应方向也不稳定。随机故障可以偶然改善当前规则策略，因此事件层标签虽准确，效用归因却未稳定恢复。当前数据只支持注入实现正确、处理效应强烈依赖 seed；不支持固定方向的剂量因果结论或规划器/执行器贡献排序。

## 下一步

以同一组 seed 120–124 做剂量 0.50 的探索性配对先导，保持四格设计不变，用相同 seed 降低跨 seed 波动。该重复剂量比较仍属于探索，因为剂量方案是看到 0.25 结果后追加的。只有确认新的 scoring/output 指标支持稳定分辨、处理方向和非线性后，才另选未使用 seed 做冻结方案的确认批次。
