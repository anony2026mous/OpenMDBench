# 网格四格剂量 0.50 配对先导方案

登记时间：2026-09-25，在剂量 0.50 数据运行前建立。此为基于剂量 0.25 结果的第二阶段探索，不作为确认性检验。

## 目的

在同一批 seed 上比较注入剂量 0.25 与 0.50 时规划器、执行器和联合干预的效用变化、实际注入事件量及跨层交互。剂量 0.25 先导显示注入可能提高也可能降低得分，因此本试验不预设所有效应必须为负，而是如实估计方向和 seed 差异。

## 固定方案

- seed 120–124，与 0.25 先导逐 seed 配对；结果仍属探索性。
- 使用同一 grid 项目源、代码、难度 `complex`、任务模式 `continuous`、间隔 5。
- 四格：clean `(0,0)`、planner `(.50,0)`、executor `(0,.50)`、both `(.50,.50)`。
- 每格一条原始运行和自身精确重放；分析 `ΔP=V(clean)-V(planner)`、`ΔE=V(clean)-V(executor)`、`ΔI=V(both)-V(planner)-V(executor)+V(clean)`。
- 质量门：全 20 格原始与重放通过、剂量及层级事件计数与配置一致、两层联合注入均实际触发、独立审计错误为空。
- 报告每个 seed 的配对效应、0.25→0.50 的同 seed 得分差、处理事件数、所有分数的观察范围；seed bootstrap 区间只作小样本描述，不据此作确认性结论。

## 判断边界

本试验描述效用变化和处理异质性，不把正效应解释成系统缺陷、也不把负效应直接解释成真实规划器/执行器贡献。注入基准组件尚未独立验证为最优 oracle；性能受场景、seed、故障类型和评分范围影响。后续确认方案必须预先冻结剂量、指标、样本量和判据，并使用新 seed。
