## 2. D1 与 P1：目前只能给非 LLM 臂的行为和分数

三个已完成臂在 20 seed 的平均 `blue_score` 分别为 `rule-rule=0.8783`、`rule-rl=0.8183`、`rl=0.8800`。缺 `llm-rule`、`llm-rl`、`pure-llm`，所以 `P/E/I/V_m/B/ΔV_A/ΔV_B` 的**完整六臂核算不可得**；`V_m` 尤其不能在缺少纯 LLM 时认定为 0.8800。

离线真值计数：`rule-rule` 共出现 12 个诱饵运输目标，其中 10 个进入记录的可见接触，命中 7 个；`rule-rl` 对应 8/0/0；纯 `rl` 对应 10/2/0（依次为总数/观察数/命中数）。各臂轨迹及动态生成的目标数不完全相同；零诱饵命中且零观察目标**不能解释为识骗成功**。这些是行为代理，不是预定时点真/假的分类准确率，也不能据此宣称 D1 的 85% 阈值通过。真实 LLM 臂的公开请求和诱饵行为尚未审计。

## 3. P2：Goal 接口消融的系统效应

20 个 seed 的 `rule-rl` strong/hold 成对自然终局均合格；hold 目标均被接收，20 对在共同前缀内均出现动作差异。逐 seed 分数差 `V(strong)−V(hold)`：平均 **+0.6067**，18 正、1 零、1 负；seed 417 为 0，seed 418 为 −0.10。按 seed 重抽样 10,000 次的探索性 95% 区间为 **[+0.4617, +0.7283]**。这表明该规则规划器＋MAPPO 组合对 Goal 消融有可观测的工程响应，但并不是 LLM+RL 的接口效应，也不是因果互信息或 `B_if` 的 bit 值。

## 4. P3b：已知故障注入的负向证据

在 seed 421–440 上，对同一规则栈做 clean、规划 Goal 故障、执行动作故障、双故障四条件（非零剂量均为 0.25），每格再做自身重放。**80/80 格原局与自身重放有效，80/80 重放精确匹配**。但以 seed 为独立单位，`V(clean)−V(fault)` 的估计是：

| 故障 | 平均损失 | 正/零/负 seed | 探索性 95% bootstrap 区间 |
|---|---:|---:|---:|
| 规划 | +0.0117 | 6 / 10 / 4 | [−0.1217, +0.1500] |
| 执行 | +0.0550 | 7 / 9 / 4 | [−0.1200, +0.2367] |
| 双故障 | +0.0133 | 6 / 8 / 6 | [−0.1467, +0.1800] |
| 四格非加性 | +0.0533 | 8 / 5 / 7 | [−0.1600, +0.2867] |

所有区间均跨零，且存在注入后得分反而改善的 seed。本剂量与评分下，**不能宣称故障损失稳定、剂量单调或诊断器已验证定位能力**。注入位置已知，不等于对未知故障的盲判成功；自身重放也只证明同配置可复现，不能证明参考组件是 oracle。参考替换代码仅有单 seed 工程冒烟，质量未经独立验证，输出继续标 `oracle_causal_attribution_validated=false`。

## 5. 下一步与论文措辞

1. 端点从当前运行环境可达后，在**同一 v2 campaign** 用 `--resume` 补三条真实 LLM 臂；先单 seed 测试实际请求、真值泄露与成本，再继续批量。若 runner、grid 源、checkpoint 或模型版本改变，必须新建 campaign。
2. 补齐六臂后才计算同 seed `P/E/I/B` 和分层盈亏；另用未参与公式构造的新 seed 验证候选分层规律。v2 现有三个便宜臂不足以证明混合收益。
3. 对 LLM+RL 另做 strong/hold 配对，不能将规则规划器的 P2 效应直接外推到 LLM 规划器。
4. 若论文继续主张反事实归因，需要预先定义未知故障的盲判规则、核验参考组件质量并评估多剂量与跨场景；当前只能写“可精确重放的已知故障干预框架，初次效应检验未建立稳定定位”。

操作命令和证据等级详见 `GRID_角色C_6.0同口径实验使用指南.md`。本报告只总结现有数据，不把缺格、零观察或未验证的 oracle 写成成功。
