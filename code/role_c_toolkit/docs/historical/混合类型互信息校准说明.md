# B_if 测量补充：混合类型估计器校准

日期：2026-09-24。状态：估计器合成校准完成；不是新的 grid 或高保真场景测量结果。

## 为什么增加这一项

上一批 grid 的全状态离散编码每步唯一，180/180 局的经验 MI 退化为目标熵。增加种子数不能自动解决这个表示问题。另一方面，论文中的目标流包含离散类别，不能直接把类别编号和连续状态一起交给普通连续 KSG。

新增 `mixed_information.py` 实现离散类别与连续向量的 Ross 近邻 MI。方法依据为 [Ross 2014 原论文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0087357)；邻居计数约定也核对了 [scikit-learn 官方实现](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/feature_selection/_mutual_info.py)。采用同类别第 k 个其他邻居半径；无距离并列时，“严格半径内含自身计数”与“闭半径内其他邻居计数”相等，使用对应的 digamma 项，不额外加 1。

本实现采用更严格的输入门禁：不删除稀有类别，不自动减少 k，不加抖动，不将负估计截断为零；非恒定重复连续向量及邻域边界距离并列会明确拒绝。恒定变量返回零并附诊断。实现允许连续向量，但本次已知真值校准只覆盖一维高斯混合，不意味着任意高维表示都已经标定。

这是一项需要在论文方法节明确说明的估计器适配，不把 Ross 改名为 KSG，也不默默替换历史数值。

## 事前固定的校准设计

校准程序不读取游戏轨迹、胜负或目标参数。先落盘 `protocol.json`，再生成数据：

- 合成随机种子 2000–2019，与场景 seeds 100–119 分开。
- 二元等概率 G，连续状态 `S = a(2G−1) + Z`，其中 Z 是独立标准正态。
- a 为 0、0.5、1.5；样本量为 200、2000；k 为 3、5、10，全部组合保留，共 360 条估计记录。
- 理论 MI 用已知概率模型的 Gauss–Hermite 求积计算，并比较 80 与 160 阶结果。
- 每组同时计算随机置换标签的独立对照及唯一连续值被误当类别的离散经验 MI。
- 预设工程校准检查：n=2000 时，各条件的绝对平均偏差和置换对照绝对均值均小于 0.08 bits。这不是论文 D3 梯度阈值，也不是正式置信覆盖率检验。

所有候选 k 的结果都输出，没有按哪个参数更接近期望来挑选唯一结果。

## 结果

下表只为便于阅读列出中间档 k=5、n=2000；完整 18 个条件均在 JSON 中。

| a | 理论 MI（bits） | 20-seed 估计均值 | 置换对照均值 |
|---|---:|---:|---:|
| 0 | 0 | 0.00619 | -0.00230 |
| 0.5 | 0.16075 | 0.16497 | -0.00180 |
| 1.5 | 0.75998 | 0.76245 | -0.00106 |

n=2000 的九个条件全部通过上述工程校准检查，最大绝对平均偏差为 0.00619 bits。80/160 阶求积的最大差约为 1.74e-9 bits。360 条估计中有 48 条负估计，原样保留，主要用于避免独立条件的有限样本波动被截断后产生上偏。

新增 13 项测试通过，覆盖暴力计数公式、类别重命名、独立和分离分布、常量、稀有类别、重复点、距离并列、缺失值与输入不变性。连同现有测试共 42/42 项通过。

## 对正式实验的意义与限制

1. 已具备一个经过基础校准的混合类型工具，能够区分合成独立与已知依赖分布，不再必然被唯一状态标签的列联表饱和所误导。
2. **不能据此直接重算 grid。** 格点位置、弹药和离散动作仍是离散变量；不能为使用本工具而添加未声明噪声。grid 需要另行固定具有充分重复支持的离散表示或采用经过验证的离散估计方案。
3. **也不能直接宣称高保真可用。** 连续坐标并不保证与存活标记、离散资源量拼接后仍有连续密度。目标类别过多、罕见目标、样本少和时序相关仍可能使估计不可用。模型接受输入不是数据假设成立的证据。
4. 下一版表示必须先声明采样时钟、实体集合、生命周期分层、编码与信息损失，再通过负对照和样本量诊断。已看过的 seeds 100–119 可作为探索数据，不应冒充新编码的未见确认集。
5. 本轮不修改既有 700 份 episode，不重写已有 B_if 或归因结果，也不改变“D3 和正式归因尚未通过”的结论。
