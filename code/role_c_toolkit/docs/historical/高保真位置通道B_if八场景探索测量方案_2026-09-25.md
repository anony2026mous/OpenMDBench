# 高保真位置通道 B_if 八场景探索测量方案

登记时间：2026-09-25，在八场景估计运行前建立。测量对象是游戏智能体的 Goal 接口与执行响应。

## 理论依据与范围

论文初稿把 B_if 操作化为 Goal 流与执行状态间的近邻互信息。完整结构化 Goal→全状态 MI 仍存在高维稀疏和点质量问题。本方案先测一个明确的确定性投影：每个固定控制单位、每个 tick，将“Goal 中是否含 target position + 三维 target position”与“同一单位该 tick 执行后的三维 position”配对。该投影的总体 MI 不大于完整信息的 MI；有限样本估计本身不保证下界。

估计使用 Gao 等（NeurIPS 2017）混合测度 k-NN 方法：名义类别 one-hot 间距固定为 4，连续变量按样本标准差标准化；`k=ceil(n^0.40)`；不加抖动、不丢弃原子/类别、不截断负值。它不是普通 KSG；本设置只在 1199 个 IID 合成样本的 3D 位置投影上通过了预设工程校准。

## 固定数据与流程

- 场景：IE-01 至 IE-08；使用已有 seed 100、完整自然终局、独立原始/重放审计通过的轨迹。场景及审计文件逐项锁定在 `hifi_bif_eight_scenes_manifest.json`。
- 对每单位选择在第一组 pre-execution Goals 出现的实体；每 tick 选该单位最高 priority Goal，同分时沿用原追踪器的首个 tie 规则；保留整段自然终局轨迹。
- X 类别：target-position 字段存在/不存在；X 数值：target-position xyz，不存在时用零并由类别标识；Y：相同单位 transition 后 position xyz。
- 逐单位计算，不跨实体类别汇合；每场景逐一报告轨迹长度、估计器 k、零半径/重复点比例和非零半径边界并列比例。
- 只有 `n=1199` 与校准样本量匹配。其他长度仍保留诊断估计，但标为样本量外推；边界并列率 >2% 标为支持门未过。不得对负数估计截零。

## 解释界限

该数据每场景仅一个 seed。整 tick 样本有明显自相关；合成 IID 校准不证明轨迹独立。此测量为探索性位置通道 MI，不等同于完整 B_if，不验证 D3 粒度梯度，不可用来检验层级定律。后续确认需在场景/seed 配对层面复现，并先解决短终局场景的有效样本支持问题。

方法来源：Gao, Kannan, Oh & Viswanath, “Estimating Mutual Information for Discrete-Continuous Mixtures,” NeurIPS 2017, https://papers.nips.cc/paper_files/paper/2017/file/ef72d53990bc4805684c9b61fa64a102-Paper.pdf
