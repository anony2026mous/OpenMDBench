# 网格旧版 KSG 耦合结果逐 Seed 复核报告

日期：2026-09-25  
范围：复核已有 grid medium 3×3 task-mode × goal-granularity KSG trace；不替代当前 grid 20-seed 新批次，也不替代 4.0 IE-01～IE-08 hybrid 实验。

## 结论

对 `openmd/code/results/coupling_traces_medium.jsonl`（LLM planner）与 `coupling_traces_medium_rule.jsonl`（rule planner）按 seed 独立重算后，18 个 architecture × task-mode × tier 条件的 pooled KSG 结果均与既有 JSON 完全一致，最大绝对误差为 **0**。逐 seed 重算揭示了旧结果没有报告的 seed 方差：weak 到 strong 的配对差异在六个 architecture × task-mode 组中，其 95% bootstrap 区间均包含 0。因此此数据不支持 D3 的“粒度梯度超过估计方差”门禁。

该复核也发现测量口径限制：旧实现定义 `B_if = max(C_info − residual_MI, 0)`，会把负的有限样本差值裁成 0；逐 seed 未裁剪值中，多组出现负值。两组 continuous/strong 的 seed 101 trace 短于 KSG 的最低窗口支持，保留为不可估，不进行填零或剔除后冒充六 seed 方差。故该复核可用于校验历史结果与暴露估计不确定性，**不构成正式 B_if / D3 通过结论**。

## 数据与复算方法

- 原始输入：LLM 和 rule 两份 `coupling_traces_medium*.jsonl`；仅使用每个条件的 `variant=layered` trace，按 task mode、granularity、seed 分组。
- 估计器：直接调用 grid 项目 `openmd/code/coupling_mi.py` 的 KSG Type-1 实现；每条 trace 依原定义汇总为不重叠 3-step 窗口。单 seed 输出 `C_info`、`residual_MI`，并计算未截断 `raw_B_if = C_info − residual_MI`。历史截断值另外保留用于对照。
- 不确定性：对可估 seed-level 量按 seed 重抽样 5000 次，报告均值、样本 SD、95% percentile bootstrap CI。weak/strong 按同一 seed 配对计算差值，再以 seed 为重抽样单位。
- 完整复算核验：同一分组把各 seed 原始 episodes pooled 后再次调用历史估计器，并与旧 summary 的 pooled 截断 B_if 比较；18/18 精确一致（max abs error 0）。
- 可复现分析代码：[analyze_legacy_grid_ksg_by_seed.py](/D:/Harness%20workspace/source-code-New-architecture/role_c_measurement/analyze_legacy_grid_ksg_by_seed.py)。机器可读结果：[analysis.json](/D:/Harness%20workspace/source-code-New-architecture/role_c_measurement/artifacts/grid-legacy-ksg-seed-audit-v1/analysis.json)。

## 对实验结论的影响

1. **复现性通过不等于构念有效性通过。** pooled 数值可从原始 trace 精确复算，但该估计量仍是领域状态耦合减少量代理，不是草稿 §5.2 所说的一般 goal-stream 到 execution-state-stream 直接互信息；必须在报告和论文中保留其操作定义。
2. **不支持粒度单调梯度。** strong−weak 的六组配对区间全部跨 0；不可用 pooled 点估计宣称 D3。weak/medium/strong 的完整非单调形状见 `analysis.json`。
3. **裁剪造成信息损失。** 旧 B_if 将 `C_info−residual_MI<0` 设为 0，会隐藏 estimator noise/模型不适配；新结果另报 raw 差值，不把负估计解释为负的总体互信息。
4. **时序依赖与有效样本数仍未解决。** 3-step 聚合并不会使时间序列自动独立；本次 seed bootstrap 只表示 seeds 间波动，不覆盖每条轨迹内 KSG 偏差，也不把窗口数当独立 seed 数。
5. **不扩张为高保真结论。** 此处是旧 grid 的 LLM/rule 数据。高保真当前运行批次是 `planner=rule` 基线；目标 vLLM `localhost:33606` 仍不可达，故没有真实 LLM+GOAI 的 IE-01～IE-08 B_if 数据或高保真归因验收数据。

**验收状态：**历史 grid KSG 数值已逐 trace 复算；逐 seed 方差与梯度已补报；D3 未通过；归因五臂/因果标签验证未由本报告覆盖；高保真 hybrid 正式测量仍未完成。
