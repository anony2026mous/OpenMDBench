## 解释

随着剂量从 0.25 加到 0.50，平均规划器和执行器损失都有增加，但对应配对区间跨零；增量主要受 seed 122 与 124 的较大变化影响。剂量 0.50 下规划器损失在 4/5 seed 为正，执行器损失在 3/5 为正。高剂量已知故障会将大量 seed 推到共同分数平台；小剂量则有时提升得分。两者说明处理效应依赖 seed 和剂量，当前先导不能给出普遍的层级贡献排序。

本先导的目的只是定位可继续研究的剂量区域。其种子数少、剂量方案根据先导逐步调整，而且无故障规则策略未经独立 optimality 验证。下一阶段应在新 seed 上冻结多剂量设计与分析方式，并采用有明确性能含义、避免平台的结果量；否则即使得到统计差异，也只能描述当前规则栈对特定注入的响应。
