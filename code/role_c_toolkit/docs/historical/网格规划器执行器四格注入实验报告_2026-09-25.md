# 网格规划器 × 执行器四格故障注入实验报告

日期：2026-09-25  
用途：游戏智能体架构诊断；本报告记录已知注入故障的流程与层级标签恢复实验，不是作战用途分析。

## 摘要

在 4.0 项目中的 grid 场景，以 seed 100–119 完成 20 组配对四格实验。四格分别为无故障、仅规划器故障、仅执行器故障、两层同时故障。每格有原始运行和基于自身轨迹的确定性重放。独立审计覆盖 80 个 seed×条件格（160 条轨迹），完整性错误为零。

规划器单层与执行器单层故障各自在 18/20 个 seed 上产生了可检测效用损失，层级标签恢复率均为 90%。但是三个故障条件的平均效用都精确落在 0.20 的评分下限。两层同时故障的 20/20 个 seed 也都在下限，导致交互项与无故障基线到下限的距离完全相同。结果支持“注入机制能触发、重放可复现、单层标签可恢复”的工程结论；高剂量饱和和未经独立验证的无故障组件意味着它不能证明论文层面的规划器/执行器 oracle 归因、B_if 测量或耦合定律。

## 实验设计

| 项目 | 设置 |
|---|---|
| 项目 | `D:\Harness workspace\source-code-4.0\source-code\openmd` 中的 grid 场景 |
| seed | 100–119，共 20 个；四个实验格按相同 seed 配对 |
| 难度 / 任务模式 | `complex` / `continuous` |
| 规划器 | 非零剂量 1.0；注入错误目标选择 |
| 执行器 | 非零剂量 1.0；注入最近接触目标改选 |
| 四格 | clean `(0,0)`、planner `(1,0)`、executor `(0,1)`、both `(1,1)` |
| 回放 | 每个原始报告由同格原始轨迹进行自身重放，需逐步精确一致 |
| 独立审计 | 校验源与报告哈希、事件日志、剂量、层级事件数、得分一致和重放精确性 |
| 效应区间 | 以 seed 为重采样单位，1000 次 bootstrap，随机种子 0，95% 百分位区间 |

用户要求设备关机时，seed 101–119 批次在 seed 105 中途暂停。旧目录保留，不覆盖、不将 seed 105 半成品纳入结果。恢复后在新目录完整重跑 seed 105–119；seed 101–104 从旧目录的完整原始报告恢复元数据后单独独立审计。所有 20 个 seed 最终均有四格完整结果。

## 结果

| 条件 | 平均效用 | seed bootstrap 95% 区间 |
|---|---:|---:|
| 无故障 | 0.710 | [0.567, 0.837] |
| 仅规划器故障 | 0.200 | [0.200, 0.200] |
| 仅执行器故障 | 0.200 | [0.200, 0.200] |
| 两层同时故障 | 0.200 | [0.200, 0.200] |

每个 seed 的预注册式四格效应计算如下，其中 `V` 为效用：

```text
规划器单层损失 ΔP = V(clean) - V(planner)
执行器单层损失 ΔE = V(clean) - V(executor)
交互项 ΔI = V(both) - V(planner) - V(executor) + V(clean)
```

| 效应 | 20 seed 平均 | seed bootstrap 95% 区间 | 解释 |
|---|---:|---:|---|
| ΔP | 0.510 | [0.367, 0.637] | 18/20 seed 为正；另 2 个基线已在评分下限 |
| ΔE | 0.510 | [0.367, 0.637] | 18/20 seed 为正；另 2 个基线已在评分下限 |
| ΔI | 0.510 | [0.367, 0.637] | 每个 seed 都等于 `V(clean)-0.20`，是评分下限造成的代数结果，不能解读为已发现规划器与执行器之间存在同等大小的真实协同作用 |

seed 111 与 seed 119 的 clean 得分已为 0.20，因此两种单层损失均为零，标签不能从效用变化恢复。其余 18 个 seed 两种单层干预均造成正损失。两层注入事件在联合格 20/20 个 seed 均被实际记录；所有重放精确。

## 结论与后续实验

本轮完成了四格设计的工程闭环和已知故障层级标签检查。在评分较高的 18 个 seed 上，系统正确把规划器干预识别为规划器层、把执行器干预识别为执行器层；联合条件两种故障均有事件证据。效用的三种注入条件完全饱和在 0.20，因此效应交互项没有可分辨的机制含义。

若要把该设计推进到论文级归因，下一轮应先用预先固定的中低剂量（例如 0.1、0.25、0.5）寻找不过早触底的工作区间，同时检查实际被干预决策数；再采用经独立验证的规划器和执行器参考策略，保证同一场景/seed 的公平对照；并以连续效用或多项结果指标做敏感性分析。剂量与主要效用指标应在看结果前锁定。高剂量本轮结果可作为注入有效性和评分下限的诊断，不能代替这些验证。

这组实验不提供 B_if 估计，也没有测量不同 Goal 粒度下的信息耦合；它不解决高保真 IE-01 至 IE-08 的正式 B_if 与完整归因验收项。
