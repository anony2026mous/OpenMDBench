# Grid A10 故障剂量响应 holdout 分析报告

日期：2026-09-25。该批次是游戏智能体规则/启发式栈上的注入机制诊断，不是高保真 LLM+GOAI 实验，也不等同于 oracle 组件归因。

## 结果摘要

预注册的 executor 严格剂量响应门**未通过**。20 个 holdout seed、六个条件共 120 个原始运行和 120 个自身重放全部完成。独立审计检查 120 对，`errors=[]`；每个 replay 均精确匹配原轨迹。总体 executor 配对效应为：剂量 0.1 的平均效用损失 0.133（95% seed-bootstrap CI [-0.093, 0.352]），剂量 0.3 为 0.152（[-0.003, 0.307]），剂量 0.5 为 0.102（[-0.057, 0.253]）。0.3−0.1 增量均值 0.018（[-0.163, 0.200]），0.5−0.3 增量均值 -0.050（[-0.238, 0.137]）。均值不严格递增，且两个相邻剂量差区间下界均未大于 0。

这不是“故障无影响”的证明；区间宽、seed 间差异大。结果说明在当前规则/启发式栈和这组 grid 场景下，注入剂量不能可靠预测效用损失。效用损失定义为 `ΔE_d = V(clean) − V(executor_d)`，保留负值；负值表示该 seed 的故障臂分数高于 clean，不能解释为注入真正提升了组件能力。

## 冻结设计与执行完整性

执行并遵循 `网格A10剂量响应holdout预注册_2026-09-25.md`：grid complex / continuous、interval=5、新 seeds 125–144；每 seed 六臂：clean (0,0)、planner_noise (.1,0)、executor (.0,.1/.3/.5)、balanced_mild (.1,.1)。效用为引擎原始 composite `V`，不裁剪、不排除 seed。Bootstrap 以 seed 为单位、10,000 次、PCG64、固定 seed 20260925。

独立审计 `artifacts/grid-a10-dose-holdout-s125-144-v1-audit/audit.json` 核验结果：120/120 条件完整；原始报告与轨迹、注入事件日志 hash 均一致；重放与原始 `V` 相同且 `exact_match=true`；源代码清单一致；剂量 assignment 与故障包装器版本匹配；无错误。clean 臂无注入事件；planner-only、executor-only 和 balanced 臂观测到的事件均局限于声明层。20 个 seed 上 planner-only 共记录 139 个 planner 事件；executor 0.1/0.3/0.5 分别记录 627/1663/2910 个 executor 事件；balanced mild 记录 135 个 planner 与 594 个 executor 事件。零事件 seed（若有）仍按 ITT 保留在效用分析中。

## 汇总统计

所有区间为 seed-level paired bootstrap percentile 95% CI；SD 是 20 个 seed 效应的样本标准差。

| 配对效应 | 均值 | seed 间 SD | 95% CI |
|---|---:|---:|---:|
| ΔP：clean − planner_noise | -0.008 | 0.430 | [-0.192, 0.178] |
| ΔE₀.₁：clean − executor₀.₁ | 0.133 | 0.519 | [-0.093, 0.352] |
| ΔE₀.₃：clean − executor₀.₃ | 0.152 | 0.363 | [-0.003, 0.307] |
| ΔE₀.₅：clean − executor₀.₅ | 0.102 | 0.373 | [-0.057, 0.253] |
| ΔI_balanced | 0.072 | 0.620 | [-0.202, 0.335] |
| ΔE₀.₃ − ΔE₀.₁ | 0.018 | 0.427 | [-0.163, 0.200] |
| ΔE₀.₅ − ΔE₀.₃ | -0.050 | 0.434 | [-0.238, 0.137] |

其中 `ΔI_balanced = V(balanced) − V(planner_noise) − V(executor₀.₁) + V(clean)`；其宽区间反映明显 seed 异质性，不能据均值称为跨层协同。注入事件数在独立运行中总体随设定剂量增加，但单 seed 事件数也会受轨迹分叉影响；事件数不是效用剂量趋势的替代终点。

## 对后续工作的含义

这轮可作为“故障标签与 replay 管线有效、但此 grid 规则栈上效用剂量可识别性不足”的阴性/设计诊断结果。它不能回答论文所需的 oracle execution / oracle planning / oracle full 反事实，也不能验证混合架构耦合定律。逐 seed 的显著正负翻转提示正式归因不能只报告总体均值；需要先提升 clean 参考栈的独立质量证据、检查 `V` 的 ceiling/floor 和轨迹依赖，并在冻结场景后对 LLM+GOAI 的关键对照重做盲化、多 seed 实验。不得按这批结果事后重选剂量或删除反向 seed。
