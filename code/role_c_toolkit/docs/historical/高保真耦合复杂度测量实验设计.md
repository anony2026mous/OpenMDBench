## 1. 背景与目标

### 1.1 研究问题

核心假设（论文 H1/H4/H5）：

- **H1**：LLM+执行器混合架构在多域对抗仿真中显著优于纯 LLM 与纯 MARL/规则基线。
- **H4/H5**：混合优势的条件性——优势由"跨层信息耦合"驱动，仅在规划层拥有执行层不可得信息（C_info>0）、且该信息能通过 goal 接口有效传递（B_if>0）时成立。

### 1.2 耦合定律（grid 阶段修正后）

$$
\Delta V = -c + f(C_{info},\ B_{if}) \cdot \mathrm{headroom}(V_m)
$$

- $\Delta V$：混合系统相对 mono（单层）执行基线的性能增益；
- $C_{info}$：规划层独有、执行层不可得的信息量（信息不对称）；
- $B_{if}$：goal 接口把规划层信息传递给执行层的有效容量（接口耦合）；
- $\mathrm{headroom}(V_m)$：mono 基线的提升余量（1 − 饱和水平）；
- $-c$：分层携带的固定接口成本。

本文聚焦 **$C_{info}$ 与 $B_{if}$ 的测量**——它们是定律中唯一"结构可测"的两项。

### 1.3 grid 阶段 KSG 方法失败回顾（动机）

`openmd-main/code/coupling_mi.py` 采用 KSG Type-1 k-NN 互信息 + 离散条件互信息分解（`B_if = C_info − residual`）。实测四条缺陷：

| 缺陷 | 代码位置/表现 | 后果 |
|---|---|---|
| 观测性而非因果性 | `I(S_usv;S_uav)` 测位置相关 | C_info 非单调（ind 2.24 < seq 2.31 > cont 1.50），与 tier 设计相反 |
| 离散分组退化 | `discrete_conditional_mi` 组内 <20 跳过、覆盖 <0.5 回退 | B_if 被强制为 0（cont×weak B_if=0.000） |
| k-NN 高维/小样本脆弱 | KSG 6 seeds 方差大 | B_if 三档平坦（0.53/0.48/0.61），无梯度 |
| 测错基材 | 只统计位置相关 | 忽略 D1′ 要求的"语义意图→行为"耦合 |

### 1.4 本文目标

提出并规范化 **三种互补的耦合测量方法**，分别从**因果、预测、语义**三个口径测量 $C_{info}/B_{if}$，使其在高保真（连续、多域、高维、语义负载高）场景下稳健、可操纵、可交叉印证。

## 2. 术语与操作化定义

| 符号 | 定义 | 测量口径（对应方法） |
|---|---|---|
| $C_{info}$ | 规划层独有信息量 | M-DO（干预版）、M-PMI（条件 MI 上限） |
| $B_{if}$ | goal 接口有效传输容量 | M-DO（因果版）、M-PMI（预测版）、M-PCF（语义版） |
| $C_{effective}$ | 实际策略下表现出的行为耦合 | 方法二 |
| $\Delta V$ | 混合相对 mono 的增益 | 统一由 2×2 锚点 + 主表给出 |
| $\mathrm{headroom}(V_m)$ | mono 基线提升余量 | 由 D2 锚点标定给出 |
| goal 粒度（granularity） | 接口信息粒度三档 weak/medium/strong | 三方法共用操纵变量 |
| 任务耦合模式（task_mode） | independent/sequential/continuous | 三方法共用操纵变量 |

**goal 接口（高保真 V2 语义）**：混合架构中，LLM 规划层通过 `ActionBatchV2`/`GoalCommand`（`navigation`/`hold`/`fire_weapon`/`send_message` 等）向执行层下发目标；执行层（MAPPO/MILP+PID/启发式）将其翻译为底层控制。$B_{if}$ 即"该接口实际改变执行层行为的程度"。

## 3. 通用实验设置（三方法共享）

### 3.1 环境与场景

- 环境：OpenMDBench 高保真 V2（`source-code/source_codes`）。
- 场景：pilot 取 3–4 个满足 D1/D1′ 的欺骗场景（真假目标数值特征不可分、核心决策为组合调度形态）；主实验 36 场景 × 3 难度。
- 角色约定：`faction.defender`=防守方=被测系统；`faction.intruder`=进攻方=标准化脚本。

### 3.2 被测系统族（2×2 锚点 + 主表）

| 规划层 \ 执行层 | heuristic | MAPPO(goal-conditioned) |
|---|---|---|
| rule | rule+heuristic（纯基线） | rule+MAPPO |
| LLM | **hybrid**（LLM+heuristic） | LLM+MAPPO |
| 无 | — | pure_rl（mono 基线） |

- 纯 LLM（LLM 直接控制）与纯规则作为对照。
- 三档 goal 粒度（weak/medium/strong）与三档任务耦合模式（independent/sequential/continuous）作为**操纵变量**，仅用于耦合测量实验。

### 3.3 数据采集协议

- 每局落盘完整 L1 指标 + **逐步轨迹**（`--dump-traces`），含：step、各实体状态、goal 命令（含粒度签名）、执行层实际动作、接触/锁定/交战事件。
- 轨迹格式对齐 grid 的 `coupling_mi.py` 输入，但**扩展**：保留连续状态（位置/速度/朝向/传感器）、goal 的原始字段（非粗粒度签名）、以及执行层动作向量。

### 3.4 统计口径（一次定死）

- 配对设计：**20 局配对 / 系统 / 条件**，seeds **100–119**，跨系统配对。
- 区间估计：bootstrap 95% CI（1000 次重抽样）。
- 假设检验：Wilcoxon signed-rank（配对）、Spearman 秩相关（单调性/相关性）。
- 单调性判据：granularity/task_mode 三档的 $B_{if}$ 估计**单调**，且相邻档间距大于估计方差（bootstrap SE 的 2 倍）。
- LLM 可靠性约束：None 响应率 ≤5%、JSON 解析错误率 ≤5%（E 组）。

## 4. M-DO：干预式因果互信息（do-Goal）

### 4.1 原理与动机

$B_{if}$ 的语义是"goal 是否**因果地**改变执行层行为"。观测性互信息混淆了"goal 驱动的耦合"与"共享环境导致的共动"。干预式方法用 **do-算子** 直接回答：对 goal 施加干预，执行层行为是否随之改变。

### 4.2 变量

- **处理变量（干预）**：goal 命令 $G$，干预集 $\mathcal{G} = \{G, G', G_\varnothing\}$：
  - $G$：真实规划输出；
  - $G'$：扰动 goal（交换目标 / 平移 waypoint / 反转优先级 / 改 ROE）；
  - $G_\varnothing$：安慰剂（重复下发同一 goal，控制"重下发"本身的影响）。
- **结果变量**：执行层动作序列 $A_{1:T}$（或行为轨迹）。
- **协变量（固定）**：初始状态 $S_0$、随机种子（保证配对可复现）。

### 4.3 实验设计（配对反事实）

对每个 (seed, 初始态) 运行三条**同种子**轨迹，只改变 goal：

```
轨迹1: G   → A^{(G)}
轨迹2: G'  → A^{(G')}
轨迹3: G∅  → A^{(G∅)}
```

在 3 档 granularity × 3 档 task_mode 的 9 个格子中各执行。

### 4.4 估计量

**因果行为分歧度**（行为距离，稳健于高维）：

$$
B_{if}^{causal} = \mathbb{E}_{S_0}\left[\ \mathcal{D}\!\left(\hat P(A\mid \mathrm{do}\,G),\ \hat P(A\mid \mathrm{do}\,G')\right)\ \right]
$$

其中 $\mathcal{D}$ 取以下任一并作稳健性对照：

1. **归一化动作距离**：$D_1 = \frac{1}{T}\sum_t \|a_t^{(G)} - a_t^{(G')}\| / \sigma_a$（控制幅值归一化）；
2. **行为不一致率**：$D_2 = \frac{1}{T}\sum_t \mathbf{1}[\|a_t^{(G)}-a_t^{(G')}\| > \varepsilon]$（超阈值步占比）；
3. **轨迹 Hausdorff/DTW 距离**（对位置型行为）。

**安慰剂基线**：$D_\varnothing = \mathcal{D}(A^{(G)}, A^{(G_\varnothing)})$ 应 ≈0，用于扣除"重下发"与噪声。净因果耦合：$\hat B_{if} = D_1 - D_\varnothing$。

**C_info 干预版**：将干预对象换成"规划层可见、执行层不可见的信息 $I$"（有/无情报注入），重复上述流程，得到信息不对称的因果效应。

### 4.5 分步流程

1. 选定 pilot 场景，冻结环境版本与 2×2 系统族。
2. 定义干预集 $\mathcal{G}$（每档 granularity 一组）。
3. 生成配对轨迹（同 seed），落盘 goal + 动作序列。
4. 计算 $\mathcal{D}$ 与 $D_\varnothing$，得 $\hat B_{if}$ 与 95% CI。
5. 9 格 + 跨系统（hybrid / rule+heuristic / LLM+MAPPO）汇总。
6. 输出：granularity 与 task_mode 上的 $B_{if}^{causal}$ 单调性曲线。

### 4.6 数据要求

- 可注入 goal 的接口（Polling API 已支持；需要"指定 goal"的干预通道）。
- 确定性回放（引擎已保证；配对轨迹同 seed 必须逐事件一致）。
- 每局逐步动作向量（L1 轨迹）。

### 4.7 有效性/健全性检验

| 检验 | 预期 | 失败含义 |
|---|---|---|
| 安慰剂 $D_\varnothing \approx 0$ | 无"重下发"伪效应 | 存在动作噪声，需加大 $\varepsilon$ 或换 $\mathcal{D}$ |
| 无耦合执行器（随机执行器）→ $\hat B_{if}\approx0$ | 干预无效 | 度量对噪声敏感 |
| granularity 三档 $\hat B_{if}$ 单调 | 接口粒度真实影响行为 | 若仍平坦 → 执行器不响应 goal（与 grid 同因，需先修执行层） |
| 与观测 KSG 对照 | 干预单调处 KSG 可能仍平坦 | 印证"观测 vs 因果"差异 |

### 4.8 验收判据

- 单调性：granularity 三档 $\hat B_{if}$ 单调、相邻档间距 > 2×bootstrap SE。
- 安慰剂 $\hat D_\varnothing$ 的 95% CI 包含 0。
- 最细档 $\hat B_{if} \ge 0.3$（信息确有跨层流动，对应 D3）。

## 5. M-PMI：模型化预测信息（Predictive MI）

### 5.1 原理与动机

$B_{if}$ 可写为条件互信息 $I(A; G \mid S)$——"在已知状态 $S$ 之外，goal $G$ 对执行层动作 $A$ 的额外预测能力"。用**训练神经网络做预测**来估计该量，替代 k-NN，规避高维与小样本问题。

### 5.2 模型与估计量

训练两个同容量的策略头：

- goal-blind：$\hat p_\phi(a\mid s)$；
- goal-conditioned：$\hat p_\psi(a\mid s, g)$。

**预测信息下界**（对数似然增益，即条件 MI 的下界）：

$$
\hat B_{if}^{pred} = \frac{1}{N}\sum_{i=1}^{N}\left[\ \log \hat p_\psi(a_i\mid s_i,g_i) - \log \hat p_\phi(a_i\mid s_i)\ \right]\ \text{(nats)} \xrightarrow{\times \log_2 e}\ \text{bits}
$$

**实现变体**（三选一，作稳健性对照）：

1. **分类器/回归头**（动作离散成 token）：直接优化负对数似然，最稳；
2. **InfoNCE**：对比目标 $\log \frac{e^{f(s,g,a)}}{\sum_j e^{f(s,g',a')}}$，提供稳定下界；
3. **MINE**：神经判别器估计 $I(A;G|S)$，灵活但需调参。

### 5.3 实验设计

1. 收集 goal→action 对齐样本（3.3 的轨迹扩展格式）。
2. 状态 $S$ 先过已训练 encoder（或 LLM 嵌入），降到可控维度。
3. 训练/验证/测试**按 episode 切分**（非按 step，防时序泄漏）。
4. 多种子（≥3）训练，报告均值 ± SE。
5. 输出 $B_{if}^{pred}$ 在 granularity/task_mode 三档上的曲线。

### 5.4 数据要求

- 大规模逐步轨迹（17 系统主表数据可复用）。
- 明确的 goal 字段（原始、非粗粒度签名）+ 执行层动作向量。
- 计算资源：轻量（单卡可训；无需训练策略，只训预测头）。

### 5.5 有效性/健全性检验

| 检验 | 预期 | 失败含义 |
|---|---|---|
| 打乱 goal（配对随机置换）→ $\hat B_{if}^{pred}\approx0$ | 无伪信息 | 模型过拟合状态 |
| 合成注入耦合（人为让 goal 决定动作）→ 单调 | 估计器能恢复已知 MI | 下界松、需换变体 |
| goal-blind 与 goal-conditioned 同容量 | 公平基线 | 容量差异造成伪增益 |
| 与 KSG 同数据对照 | 模型化在高维更稳 | — |

### 5.6 验收判据

- 打乱 goal 的 95% CI 包含 0。
- 合成注入校准：估计值与真实 MI 的偏差 < 20%。
- granularity 三档 $\hat B_{if}^{pred}$ 单调且档间距 > 2×SE。

## 6. M-PCF：语义/契约耦合（Plan-Compliance Fidelity + 表示对齐）

### 6.1 原理与动机

放弃"统计依赖"间接代理，直接在语义-契约层度量"规划层说的、执行层做的**是否一回事**"。由两个子度量组成：**目标遵从保真度（PCF）** 与 **表示对齐（RSA）**。此法最贴合 D1′（决策形态匹配），且输出可解释。

### 6.2 子度量一：目标遵从保真度（PCF）

**定义**：对每个下发的 goal，判定执行层是否"照做"。

$$
\mathrm{PCF} = \frac{\#\{\text{goal 被有效执行}\}}{\#\{\text{goal 下发}\}}
$$

**判定规则（按 goal_type）**：

| goal_type | "有效执行"判据 |
|---|---|
| intercept/track | 执行器朝目标接近（目标方向位移分量 >0）或触发对目标的交战/锁定事件 |
| patrol/waypoint | 执行器轨迹进入命令区域（与命令点距离 ≤ε） |
| hold/return | 执行器保持/回撤（速度≈0 / 朝向补给点位移>0） |

**补充距离度量**：执行器轨迹到命令目标区域的 **DTW/Hausdorff 距离**（连续化 PCF，避免二值化信息损失）。

### 6.3 子度量二：表示对齐（RSA）

**定义**：把"规划层意图"与"执行层实现行为"编码到共享空间，度量语义对齐。

1. 编码：goal 文本/结构化字段 → 嵌入（复用 LLM 嵌入或任务 encoder）；执行层行为序列 → 嵌入（状态/动作序列 encoder）。
2. 对齐度量：**CKA**（centered kernel alignment）或 **均值余弦相似度**（对 batch 内真配对 vs 随机配对）。

$$
\mathrm{RSA} = \mathrm{CKA}(\Phi_{goal},\ \Phi_{behavior})
$$

**空基线**：随机 goal ↔ 行为配对的 CKA（应显著低于真配对）。

### 6.4 实验设计

1. 从轨迹中抽取"goal 命令 + 对应时间窗内的执行层行为"配对。
2. 计算 PCF（含 DTW 距离）与 RSA（含随机配对基线）。
3. 在 granularity/task_mode 三档上汇总。
4. 跨系统对照：hybrid vs rule+heuristic vs LLM+MAPPO。

### 6.5 数据要求

- goal 命令 + 执行层动作的时间对齐（3.3 轨迹已具备）。
- 嵌入：LLM 文本嵌入（离线）或轻量 encoder。

### 6.6 有效性/健全性检验

| 检验 | 预期 | 失败含义 |
|---|---|---|
| "忠仆"执行器（oracle 恒服从）→ PCF≈1 | 度量上界校准 | 判据阈值 ε 不当 |
| "叛逆"执行器（恒忽略 goal）→ PCF≈0 | 度量下界校准 | — |
| 随机 goal ↔ 行为 RSA 显著低于真配对 | 对齐度量有效 | 嵌入无区分力 |
| granularity 三档 PCF/RSA 单调 | 接口粒度真实影响遵从/对齐 | 执行器不响应 goal |

### 6.7 验收判据

- PCF 上界校准 ≥0.9、下界校准 ≤0.1。
- granularity 三档 PCF（或 DTW 距离）单调。
- RSA 真配对 vs 随机配对的差异显著（Wilcoxon p<0.05）。
- **附加产出**：D1′ 决策形态匹配分 = 同场景下 rule-planner 的 PCF 与 LLM-planner 的 PCF 之差，用于判定"任务难点是否落在 LLM 强项"。

## 7. 三方法交叉印证与一致性协议

| 口径 | 方法一（因果） | 方法二（预测） | 方法三（语义） |
|---|---|---|---|
| 测量本质 | do-干预行为分歧 | 条件 MI 预测增益 | 遵从率 + 语义对齐 |
| 稳健性风险 | 需确定性回放 | 需防过拟合/泄漏 | 需阈值/嵌入质量 |
| 与 grid 缺陷对应 | 观测混淆、无梯度 | 高维/小样本、分组退化 | 测错基材 |

**一致性协议**：

1. 三条通道在 pilot 场景分别产出 $\hat B_{if}^{(1)},\hat B_{if}^{(2)},\hat B_{if}^{(3)}$。
2. **若三者在 granularity/task_mode 上单调性一致** → 结论"接口耦合梯度真实存在"，进入主实验；
3. **若仅一两条一致** → 以因果口径（方法一）为锚，其余作敏感性分析，并在论文如实报告差异；
4. **若三者均无单调梯度** → 复现 grid 的"执行器不响应 goal"边界条件，触发执行层/接口返工（D3 不过）。

## 8. 统计分析与假设检验总纲

### 8.1 主检验

- **H-D1**：C_info 正区间存在（方法一情报注入的因果效应 > 0 且显著）。
- **H-D3**：B_if 随 granularity 单调（三方法一致时结论最强）。
- **H-coupling**：$\Delta V$ 与 $B_{if}$ 正相关（Spearman ρ > 0.7），且在 headroom 未饱和格成立（验证 headroom 门槛）。

### 8.2 耦合定律拟合

对 9 格数据拟合：

$$
\Delta V_{ij} = -c + b \cdot (e^{B_{if,ij}} - 1) \cdot \mathrm{headroom}(V_{m,i})
$$

- 判据 (i) Spearman ρ($\Delta V$, $\exp(B_{if})$) > 0.7；
- 判据 (ii) $B_{if}\approx0$ 处 $\Delta V$ 的 95% CI 含 0（无耦合则无增益）；
- 判据 (iii) 指数模型 BIC 优于线性模型。

### 8.3 报告规范
