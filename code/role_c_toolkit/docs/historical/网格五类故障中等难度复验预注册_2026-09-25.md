# Grid 五类故障中等难度复验预注册

登记：2026-09-25，运行前。此复验针对 4.0 对应的 Grid 项目，用于诊断原 complex/continuous 批次的评分饱和是否妨碍归因剂量验证；不取代论文要求的正式参考组件归因实验。

## 设计

- 难度：`medium`；task mode：`continuous`；plan interval：5。
- 冒烟 seed：100；仅用于验证中等难度配置下五种边界故障的触发、日志完整性、原始/固定决策重放和评分余量。
- 五种既有故障：planner 错误目标、接口裁剪字段、接口丢失 Goal、executor 改选最近接触、action hold。
- 每类故障均有自身剂量 0 对照以及剂量 0.25、0.5、1.0；另有不带故障包装的 `none` 参考组。
- 每个 cell 运行原始 episode 与自身固定决策重放；保持现有 wrapper、事件 hash 选择规则、source tree 和评分不变。
- 运行目录使用新的 `artifacts/grid-fault-five-case-medium-s100-smoke-v1/`，不得覆盖 complex 条件数据。

## 判读规则

该单 seed 冒烟只检验实验机制与 headroom，不检验统计剂量单调性或故障标签正确率。只有 smoke 通过、medium 分数不在平台饱和、且注入日志证明确实改变目标接口/动作后，才登记 seed 100–119 的完整复验。完整复验以 seed 为配对单位做 bootstrap；dose 0.25→0.5→1.0 的各相邻均值损失 95% CI 均为正、五类的均值曲线非增且注入事件通过审计，才可称该实验剂量反应支持通过。否则如实保留失败。

## 范围限制

该实验故障注入使用规则 planner + heuristic executor，能验证层边界注入工程链路，不能证明 LLM+GOAI 混合系统中的 oracle 归因。正式角色 C 归因仍需参考组件质量独立验证、五案例标签恢复和适当配对统计。
