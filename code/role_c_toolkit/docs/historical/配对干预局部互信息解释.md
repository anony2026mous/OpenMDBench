# 配对干预的局部条件互信息：可计算，但不能偷换成论文 B_if

日期：2026-09-24。计算脚本 `measure_paired_interventions.py` 从已通过配对对照审计的 Goal 干预探针中抽取**实际执行动作**，丢弃批次 ID、回执指纹等非动作元数据，按每个锚点的明确均匀分配定义 $I_{do}(G;A\mid C=c)$；其中 C 是**完整引擎 checkpoint 加控制器状态**，不只是可见观测 O。在固定 seed/锚点、相同 C 和确定性执行器下，每个 Goal 对应一个动作窗口；因此局部条件熵 $H(A\mid G,C=c)=0$，此有限分配的信息量等于所产生动作类别的熵。它不能直接推成只条件于观测的 $I_{do}(G;A\mid O)$，也不是自然 Goal 流与执行状态的论文 KSG $B_{if}$，更不是通道容量。
