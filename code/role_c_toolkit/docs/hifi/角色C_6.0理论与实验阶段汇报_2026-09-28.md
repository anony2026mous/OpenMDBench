# 角色 C：6.0 分层理论与实验阶段汇报

日期：2026-09-28。研究对象为游戏智能体。**本文件是阶段汇报，不是论文定律验证完成报告。**数据截点为补跑后重新生成的 [P1 机器汇总](artifacts/p1_manual_20260927_b1/p1_summary.json)：预定 36 格中 18 格可认证，IE-10 已齐、IE-11 尚无合格终局；后续补跑须再次更新此处数字。配套文件为[通俗讲稿](角色C_6.0理论与实验阶段汇报_通俗讲稿_2026-09-28.md)。

## 一、研究问题与本阶段结论

我们研究的是：LLM 负责较慢的语义规划、规则或 RL 执行器负责较快的动作时，分层何时有收益，收益或损失来自哪里。角色 C 的任务不是只做架构排行榜，而是给出耦合机制、故障归因和理论边界的可审计证据。

目前最稳妥的结论是：6.0 的关键公平性与 IE-11 无标签输入门禁已通过；IE-10 已有 18 局合格自然终局，显示混合架构收益随 seed 改变方向，不能宣称稳定占优；接口裁剪、IE-11 自主识骗完整局及高保真故障注入尚未完成。因此，现阶段能够提出**新的分层盈亏核算框架与可失败的机制假说**，不能宣称新耦合定律已获高保真验证。

## 二、理论：从原条件式到可核算的新公式

[论文初稿](../source-code/openmd/doc/OpenMDBench0830.md)的原条件式为

`ΔV = −c + f(C_info, B_if) · headroom(V_m)`。

它表达三重条件：分层接口有代价 `c`；规划层必须有执行层缺少、且可合法传递的信息 `C_info`，接口也要真正传递并被使用（`B_if`）；最好的纯架构还需留有改善空间。该式仍是研究假说：目前缺少独立 oracle 来确定 headroom，也没有在 6.0 上校准的干预式 `B_if` 估计，因而不能用现有数据拟合 `f` 或检验原式数值。

在现阶段，我们改用六臂同场景、同 seed、同评分口径的**分层盈亏公式**。设 `V_x` 为对应架构的平均终局主效用；`rule-rule`、`llm-rule` 是两种规则执行器架构，`rule-rl`、`llm-rl` 是两种 RL 执行器架构，`rl` 和 `pure-llm` 是另两种纯架构：

```text
P = V_llm-rule − V_rule-rule
E = V_rule-rl − V_rule-rule
I = V_llm-rl − V_llm-rule − V_rule-rl + V_rule-rule
V_m = max(V_rule-rule, V_rl, V_pure-llm)
B = V_m − V_rule-rule

混合 A 相对最强纯架构：ΔV_A = V_llm-rule − V_m = P − B
混合 B 相对最强纯架构：ΔV_B = V_llm-rl − V_m = P + E + I − B
```

这里 `P` 是当前部署系统中固定规则执行器时的规划差；`E` 是固定规则规划器时的执行系统差；`I` 是四格的非加性差额；`B` 是必须跨过的纯架构竞争门槛。因此 A 获胜当且仅当 `P>B`，B 获胜当且仅当 `P+E+I>B`。**这些等式是精确的代数恒等式，不是经过验证的经验定律，也不能仅凭它们给 `I` 贴上“耦合度”标签。**现用 `rule-rl` 与 `llm-rl` 权重的训练来源和轮数不同，所以 `E`、`I` 仅可描述已部署系统，不能解释为无混淆的组件因果效应。

真正待检验的理论命题是：当合法 Goal 字段变化确实导致执行器编码、下一窗口动作和效用发生可复现响应，并且纯架构仍有改善空间时，分层收益才可能覆盖接口成本；若 Goal 裁剪不改变动作，便不能把主表中的 `I` 或收益归因于接口。不同场景可能出现相反方向，因此理论应允许场景条件和失败边界。由本批数据再修订出的函数形式，只能标为“探索性 v2 候选”，必须用未参与构造的新 seed/场景独立检验。

## 三、实验进展与结果

| 模块 | 当前证据 | 能支持的结论 |
|---|---|---|
| P0 门禁 | 6.0 六臂接口冒烟通过；IE-11 修复后的公开接触 ID 与三条 LLM 路径实际请求未直接暴露诱饵角色真值；开发性短跑非自然终局 | 可以开始无标签识骗能力测试；**不能**据此宣称智能体已经识骗成功。详见 [P0 报告](P0_6.0冻结版执行与门禁报告_2026-09-27.md)。 |
| P1 主表 | IE-10 已有 **18/18** 合格格；`pure-llm` seed 203 的崩溃尝试 `a1` 保留，补跑 `a2` 通过审计并入表。IE-11 为 **0/18** 合格格 | 可报告 IE-10 的完整六臂小样本均值与相对最强纯架构差；跨场景规律仍不可计算。 |
| P2 接口 | strong/weak Goal 裁剪的完整操纵尚未完成 | 尚无高保真接口效应，更无干预式因果互信息。 |
| P3a 可靠性 | 已有 9 局合格 LLM 轨迹的请求记录 | 可报告这 9 局的请求级可靠性；不能外推所有场景或把崩溃局算作完成。 |
| P3b 归因 | 6.0 外置故障注入、自身重放与已知故障定位尚未完成 | 不能宣称高保真五型归因、严格剂量单调或 oracle 因果分解。 |

| seed | rule-rule | llm-rule | rule-rl | llm-rl | rl | pure-llm |

三个 seed 上 `llm-rule − rule-rule` 依次为 **+0.3394、+0.0262、−0.2775**，均值 **+0.0294**；`llm-rl − rule-rl` 依次为 **−0.0039、+0.0017、−0.1899**，均值 **−0.0640**。方向翻转且样本只有 3 个 seed，不能报告稳定优势或显著性。18 局的引擎终局标签均为 `defender_success`，却仍存在设施失能、真实威胁漏防和投放，故成败标签不足以替代分层指标。例如 `llm-rl` 比 `rule-rl` 平均少开火约 4.33 次，但 seed 203 同时设施存活更低、漏防更多，不能将“省弹”单独解释为改进。

当前可按三 seed 核算 `P=+0.0294`、`E=+0.0532`、`I=−0.0934`；最强纯架构是均值 **0.7610** 的 `rule-rule`，故 `V_m=0.7610`、`B=0`、`ΔV_A=+0.0294`、`ΔV_B=−0.0108`。这只是 IE-10 三 seed 的部署系统成绩核算，逐 seed 胜负仍会翻转。IE-11 没有合格终局，因此诱饵误打和保弹效应是“缺失”，不是 0。详细次指标和统计限制见 [更新后的 P1 主报告](P1_6.0六臂主成绩实验报告_2026-09-27.md)；[17 格阶段分析](P1_6.0阶段性分析_崩溃前17格_2026-09-28.md)仅为补跑前历史快照。

9 局合格 LLM 轨迹共 **878** 次请求：请求错误和空回复均为 **0**，规划解析失败 **5** 次、沿用旧计划 **5** 次、真正规则 fallback **0** 次；延迟中位数约 **22.7 秒**，95 百分位约 **28.5 秒**。这些数字说明服务连接稳定，但并非每次规划都有效。崩溃中断局的部分请求不在此分母内。

## 四、与原论文和历史 grid 结果的关系

论文初稿中的 grid 结果曾提示：混合收益并不随表面耦合无条件增加，接口成本、纯架构的性能上限和决策形式匹配都重要；这为 6.0 的门禁及反例设计提供了动机。但初稿所写 grid 的 KSG 耦合值、五型故障“5/5”及严格剂量单调，**不能直接搬到 6.0 高保真结果中**。后续复核还发现历史 grid A10 的 20-seed 严格剂量响应未通过，高保真旧 KSG 在部分混合分布中不可估。论文需按各批次原始证据修订相应强表述，不能让初稿文字代替新实验。

## 五、接下来最短的证据闭环

1. IE-10 六臂表已补齐；对 `V_m/B/ΔV` 保留逐 seed 与均值两种口径、缺格/重试审计和小样本限制。
2. 完成修复版 IE-11 的六臂自然终局，核对实际提示与实体标签，计算诱饵开火、真实威胁漏防和保弹；若仍有泄题或固定 ID 记忆风险，收窄“自主识骗”表述。
3. 对 IE-10 做 `llm-rl` strong/weak Goal 接口裁剪，先用廉价臂确认 Goal、RL 编码和下一窗动作确实改变，再运行昂贵完整局；报告系统效应，不冒称因果 MI。
4. 复核请求可靠性；只有外置注入与自身重放通过时，才尝试 P3b 两类已知故障定位。新增 seed/场景用于检验任何由现有数据形成的 v2 理论候选。

**建议汇报结语：**我们已经建立可追溯的 6.0 评测入口，发现 IE-10 的混合收益具有 seed 敏感性，并给出不会把账本误认为定律的分层盈亏框架。当前最重要的科学任务是把成绩差与真实 Goal 接口响应连起来，并用独立数据检验其条件性；高保真耦合定律尚未被证明。
