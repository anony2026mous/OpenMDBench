# 角色 C 阶段汇报：通俗讲稿

日期：2026-09-28。配套正式文件：[《6.0 分层理论与实验阶段汇报》](角色C_6.0理论与实验阶段汇报_2026-09-28.md)。以下按约 5–7 分钟口头汇报组织；数字以正式文件及其原始数据为准。

## 开场：我们到底要证明什么

“我们研究的是游戏智能体，不是单纯比较哪个模型分数高。混合架构像一个两层团队：上层 LLM 想办法、定目标，下层规则或 RL 执行器快速行动。角色 C 要回答三个问题：两层合作有没有实际收益？目标信息有没有真的传到行动中？如果表现不好，问题出在规划层、执行层，还是两层的连接处？”

“所以我们的实验不只有最终分数。P0 先检查试题是否泄题、系统是否能按同一规则运行；P1 看六种架构的完整局表现；P2 故意削弱传给执行器的目标，看动作是否跟着变；P3a 统计 LLM 是否超时或答错；P3b 在条件允许时放入已知故障，测试能否找对出错层级。”

## 理论：把‘分层有用’说成可检验的条件

“原论文有一个直观公式：分层的净收益，等于信息带来的好处，减去上下层沟通的成本；而纯架构越接近满分，改进空间越小。这个想法仍然重要，但现在我们没有可靠的 oracle 和高保真因果互信息测量，直接给公式里的每个量填数字，会显得比证据更确定。”

“因此本阶段先用一个新的、能从六种系统成绩直接核算的分层盈亏公式。我们把混合系统的表现拆成四笔账：`P` 是换规划器的成绩差，`E` 是换执行系统的成绩差，`I` 是两者搭配后多出来或少掉的非加性差额，`B` 是最强纯架构比基础规则系统高出的门槛。第一种混合要胜出，需要 `P>B`；第二种混合要胜出，需要 `P+E+I>B`。”

“注意，这像会计恒等式：账一定算得平，但算平不等于证明了自然定律。真正需要证明的是：把上层传下去的 Goal 改一改，下层的动作会不会有规律地改变，进而改变成绩。如果动作根本不变，我们就不能说分层接口创造了收益。此外，当前两个 RL 执行器的训练条件不同，`I` 不能直接叫作纯粹的‘耦合因果效应’。”

## 实验：已经看到什么

“P0 已经做完关键门禁。此前 IE-11 的目标编号里直接写着‘诱饵’，这等于题目泄答案。6.0 修复后，我们检查了实际公开观测和真实发给 LLM 的请求，直接角色标签不再出现。所以现在**允许开始**测无标签识骗；但还不能说智能体**已经具备**识骗能力。”

“P1 计划是两道场景题、三个随机起点、六种架构，总共 36 场完整比赛。到这个数据截点，第一道 IE-10 的 **18 场已经全部合格**；第二道 IE-11 还没有合格的完整局。IE-10 里，把 LLM 规划加到规则执行器上，三个相同起点的得分差分别是 **+0.3394、+0.0262、−0.2775**。也就是说，前两次有利，第三次明显不利，平均 **+0.0294** 并不能代表稳定获益。另一种 LLM+RL 组合相对规则+RL 的三次差值为 **−0.0039、+0.0017、−0.1899**，平均 **−0.0640**，同样没有稳定正收益。”

“这 18 场的终局都被判为防守成功，但有些设施失能，有些来袭目标已经漏进来甚至投放过武器。只看‘赢了没有’会掩盖明显的质量差别。比如 LLM+RL 平均发射次数更少，但某个起点上它同时保护设施更差、漏防更多，所以‘少开火’不能自动算优点。”

“现在能算的账是 `P≈+0.0294`、`E≈+0.0532`、`I≈−0.0934`。第三个起点的纯 LLM 崩溃局已经重跑并通过审计，得分 **0.5965**。这样 IE-10 的六臂表就齐了：按三 seed 均值，最强纯架构是规则系统，门槛 `B=0`；LLM＋规则比它高 **0.0294**，LLM＋RL 比它低 **0.0108**。这是小样本平均分，逐起点胜负会翻转。IE-11 没有完整局，诱饵误打指标是**没有数据**，不是零次误打。”

“P3a 已经有一部分结果：9 场合格的 LLM 完整局里共有 **878** 次模型请求，没有请求错误或空回复；但有 **5** 次规划解析失败，系统沿用了旧计划。服务连通性不错，不代表每次规划都成功。P2 的 Goal 裁剪和 P3b 的高保真故障注入还没有做，因此我们不能宣称已经测到因果耦合或完成故障归因。”

## 结尾：我们下一步做什么、现在该怎样表述贡献

“下一步完成 IE-11；这样才有跨场景的六臂对照和诱饵机制数据。然后做 Goal 强弱接口实验，看目标变化是否真的引起执行变化。只有这个机制链条成立，成绩差才有资格被解释为分层接口的作用。故障注入则要等自身重放通过后再做。”

“我建议把当前成果表述为：我们建立了可信的高保真实验入口，得到一个显示混合收益并不稳定的初步反例，并提出可核算的分层盈亏框架。它帮我们精确定位还缺哪些证据；**耦合定律本身仍是待检验的条件性理论，而不是已经被 IE-10 这 18 场比赛证明的结论。**”

## 可能被问到的问题

**问：18 场都防守成功，为什么还说表现有差异？** 答：终局标签很粗；设施是否失能、目标是否漏防、是否已投放、弹药使用效率都不同。

**问：新公式是否就是论文新的定律？** 答：它首先是成绩分解恒等式，保证比较口径清楚；可作为理论组织框架，但关于接口何时带来收益的机制命题仍需 P2 和独立数据检验。

**问：P0 通过是否证明自主识骗？** 答：不是。它只证明修复后的输入不直接写出哪个是诱饵；真正识骗能力要看 IE-11 完整局的误打、保弹和真实目标应对。

**问：为什么不能把 `I=−0.0934` 直接说成负耦合？** 答：`I` 是四种已部署系统的非加性成绩差，而且两种 RL 权重训练条件不同；没有隔离接口、没有共同执行器权重时，无法把差额单独归因于耦合。

**问：原论文的 grid 结果还算数吗？** 答：它们是概念验证和实验设计动机，不能冒充 6.0 高保真验证。部分强表述需要按原始数据复核、修订，并与新场景结果分开报告。
