# ADR-004: Rules of engagement after breach

Status: Accepted

## Context

Mission state can affect which engagements are legal without changing platform identity.

## Decision

Apply the declared ROE through the common legality pipeline, including the frozen post-breach
weapon distinctions.

## Consequences

Illegal actions are rejected with auditable reasons and no side effects; the rule is data-driven
and does not create a scenario-specific combat bypass.
