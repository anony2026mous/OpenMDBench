# MD-AD-002 高度指令接线变更

## 变更原因

公开导航接口一直包含三维 `target_m`，UAV 动力学也支持有界爬升/下降，但主循环此前只传递速度和航向，并把目标高度固定为当前高度。本次将 `target_m[2]` 接入每架 UAV 的动力学命令。

## 当前语义

- `move_to`、`patrol`、`guard` 使用目标点的第三维作为目标高度；
- `hold_position` 保持当前高度；
- UAV 继续使用既有 `20 m/s` 最大爬升/下降率和 `0–3000 m` 高度边界；
- 垂直速度写入实体 `velocity[2]`；
- USV 和岸基平台不使用高度命令；
- 实时标签显示高度及上升、下降或保持趋势。

## Golden 影响

MEDIUM seed 0 的红方规则智能体会根据公开 contact 的三维位置调整拦截高度，因此确定性结果发生预期变化：

- 终局 tick：`1523 -> 1543`；
- `usv_early_warning_gain`：`0.8190628165125731 -> 0.8904451476445606`；
- 综合分：`0.7698438027520954 -> 0.7817408579407601`；
- 终局仍为 `red_success / all_threats_destroyed`，突破数仍为 `0`。

配置内容未变化，因此配置哈希保持不变；变化来自引擎执行语义修正。Golden 已按两次独立运行的相同结果更新。
