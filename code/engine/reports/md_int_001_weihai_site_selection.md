# MD-INT-001 威海任务地点选择

- 任务：I001-A04
- 地点标识：`benchmark_harbor_entry`
- 声明：这是现有威海地图上的比赛基准入口，不是现实设施精确标注。
- 地图：`weihai_v1`，version `1.0`
- WGS84 source SHA-256：`1f78cfaf98e12d3b50cd595e58e103f4c31ef3ce71b433ba276c3afa1694b675`
- legacy XY SHA-256：`6b62aa3d3434a8de27f11bdb22627c42c1d5b930c835cfbf77ce37465a00c067`

## 选择依据

入口中心调整到刘公岛东侧近海 `(122.220521637°E, 37.498906006°N)`。该点位于既有海岸线数据的水域，
岸基雷达部署在刘公岛轮廓内，USV位于岛东侧水域；保护区、两架蓝方 UAV、
USV和红方 UAV沿岛东侧来袭轴展开。海陆判定直接加载
`env/map_data/weihai_raw_lonlat.txt` 的137个多边形，没有创建替代地图。

保护区为以入口中心为圆心、半径1000 m的含边界测地圆。红方由东向西来袭。

## 自动验证

- 实际文件 SHA-256 与配置一致；不匹配时测试失败。
- `blue-radar-1` 位于至少一个真实威海陆地多边形内部。
- `blue-usv-1` 不位于任何陆地多边形内部。
- 五实体 ID、阵营、类型、经纬度、高度和 terrain 通过严格 schema。
- WGS84 测地距离：USV 1500 m、UAV-1 3500 m、UAV-2 5000 m、红 UAV 25000 m。
- 图中使用同一份威海 WGS84 边界数据，显示刘公岛轮廓、保护区、探测范围和全部部署点。

验证图：`reports/md_int_001_weihai_site.png`。

## 限制与后续

地图没有港口语义标签，因此不能把该点描述为现实港口名称。现有多边形只提供几何，没有权威陆地/水域
拓扑元数据；A04采用“多边形内部为陆地、外部为水域”的既有地图解释。B00必须建立统一 GeoFrame、
严格地图 identity、坐标往返及与 Sim2Sea offset collision 的运行时闭环。
