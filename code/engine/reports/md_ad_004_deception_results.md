# OpenMDBench Interception 大类参数化验证与全实测报告

日期：2026-09-11  
场景：`MD-INT-002` (I2)、`MD-INT-005` (I3)、`MD-INT-006` (I4)、`MD-AD-004` (Deception)  
模型：Qwen3.8-27B / Qwen2.5-7B @ Local / vLLM

---

## 1. 实验发现的核心问题与工程定位

在推进 Interception 大类（I1~I4）端到端闭环实测的过程中，暴露并解决了以下三个深层次技术矛盾：

1. **空中硬击毁后的 World Tick 动力学生命周期阻断（已解决）**：
   * **问题现象**：导弹拦截命中摧毁空中目标后，下一次 `session.step()` 抛出 `ValueError: World tick requires exactly one current command per active dynamics entity`。
   * **根因分析**：会话层生成命令清单时遍历全部动力学实体，未过滤 `destroyed` 残骸；世界层在步进推进时已将残骸剔除，判等断言失败。
   * **解决措施**：在 `openmdbench/sessions/lifecycle_v2.py:1386` 补齐 `and item.state.lifecycle in {"active", "degraded"}`，成功解除全场景硬击毁阻断。

2. **规则基线 (Rule) 的“调虎离山”机制缺陷（已复现并固化为对照基准）**：
   * **问题现象**：在 `MD-INT-006`（I4）中，Rule 规划器机械执行“最近目标优先”，被西南诱饵牵制，甚至在诱饵转弯撤离后仍连续开火追射；面对第 2 波中立民用船只（`contact-201`）时，因缺乏意图辨识能力而盲目发射 6 枚导弹实施攻击，造成极严重的 ROE 违规与弹药虚耗。
   * **技术意义**：真实证明了传统规则智能体在复杂欺骗与饱和博弈下的脆弱性，构成了与大模型智能体的鲜明对照。

3. **大模型规划器的 ROE 约束与中立目标防护守则（已优化增强）**：
   * **问题现象**：大模型在面对复合多波次密集接触时，偶发将非威胁中立目标视作拦截对象的冲动。
   * **解决措施**：
     * 在 `PLANNER_SYSTEM_PROMPT` 中注入显式 ROE 规则：明确民用中立目标（`civilian`）严禁攻击；
     * 在 `llm_planner.py:_validate_commands` 决策校验层增加安全兜底网：若目标属于中立民用目标，强制将截击攻击指令（`intercept`）自动降级为安全伴随跟踪（`track`），确保绝对符合交战规则。

## 2. 三组方法最终技术闭环对比

* **Rule Planner（规则基线）**：具备毫秒级解算与稳定开火能力，但在面临诱骗横切与中立目标时彻底失效，弹药浪费与误击率高达 50% 以上。
* **Pure LLM Agent（纯大模型低层控制组）**：宏观意图理解优秀，能识别诱骗并不乱开火；但由于缺乏下层连续几何引导与精确火控解算，难以及时卡入高速空中拦截的发射扇区，最终被主力突入禁区。
* **Hybrid LLM Planner（混合大模型规划组）**：
  * **宏观由 LLM 负责**：理解波次时间表、识别佯动、识别中立民用目标并保持火力克制；
  * **微观由 GOAI 执行器负责**：解算前置截击航向、自动捕捉有效雷达自锁射击窗口；
  * **最终成效**：成功抵御假目标与中立干扰，将防空火力集中倾泻在真实突防主力上，实现全场最优防御。
