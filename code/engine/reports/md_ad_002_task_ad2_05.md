# AD2-05 武器、ROE、同时毁伤与任务裁决阶段报告

## 完成范围

- 三个独立 MD-AD-002 配置均补充武器毁伤和冷却参数：UAV 导弹 0.5–8 km、近防 0.3–2 km。
- 新增配置驱动的 `AD2Combat`：检查红方归属、平台状态、通信、己方 contact、置信度、时效、弹药、冷却、估计/真值射程和禁入区 ROE。
- 同一目标同 tick 只允许一次射击，稳定优先级为近防、估计距离、平台 ID；获胜射击统一结算同时毁伤。
- 非法动作不扣弹、不耗能、不推进 combat RNG、不设置冷却，并返回稳定拒绝码。
- 突破在动力学之后锁存；进入 8 km 后使用 `BREACHED_ACTIVE`，后续同 tick 被毁不撤销计数。
- 新增任务裁决优先级：管理员终止、突破达到 3、红方资源耗尽、15 个目标全部摧毁、全部终态、超时。
- combat RNG、冷却、突破集合、事件与终局均进入检查点。
