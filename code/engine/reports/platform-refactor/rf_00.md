## 领域基线

## 关键架构结论

- `SimulationSession → SessionRuntime → OpenMDBenchEnv` 复用唯一 WorldState/tick 链，未发现第二套世界。
- 旧 REST `api.sessions.SessionManager` 仍直接持有 Env，与新 Gateway 并行，需在 RF-12 合并。
- MMG/Taichi 共享原生 core，未证明线程隔离；保持 spawn worker 方向。
- 平台 Session RNG 未成为所有系统的唯一 RNG 所有者，完整恢复契约未成立。
