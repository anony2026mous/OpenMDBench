## 交付能力

- WGS84、local metre、map 坐标互转，日期线、极点、航向和统一有限值/容差契约。
- 严格 Geography layer schema 与 Catalog/Resolved hash 信任链；支持 land、coast、island、no-go、terrain height、bathymetry 和 static obstacle 查询。
- 每实体 allowed/excluded zone、动态 zone activation、boundary priority 与七类受控 policy。
- Boundary/Collision facts、winning response、typed lifecycle/mission intent 与 `DamageIntentV2` 分离；空间系统不直接修改 health。
- 显式权威 tick-start、连续高速 sweep、XYZ 同时区间、确定性 broadphase 与独立 brute-force 对照。
- World 单写者 motion pipeline：CAS、幂等、整批原子提交/回滚、0/1/10/100 顺序确定性。
- MotionCandidate 强制 dynamics resource/model/adapter/Resolved/provider receipt 五锚；无 dynamics 实体使用显式 Kinematic 路径；receipt 防重放并进入 checkpoint。
- checkpoint 保存空间时钟、zone activation、motion ledger、boundary topology 和 provenance receipt。
- sphere–sphere 使用真实 3D quadratic continuous sweep；尚未实现精确 continuous sweep 的 shape 组合稳定 fail closed，不使用圆柱、矩形或 world-AABB 静默近似。
