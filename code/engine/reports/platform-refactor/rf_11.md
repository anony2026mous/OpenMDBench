## 交付能力

- `FrameBuilderV2` 从 immutable faction Observation 构造唯一 `VisualizationFrameV2`，不读取 World。
- `LiveFrameBusV2` 有界、drop-oldest、严格递增 tick；慢消费者不阻塞 Session writer。
- `ReplayHeaderV2` 锚定 session、Resolved、Catalog、Registry 与 seed。
- `ReplayRecordV2` 锚定 frame、World checkpoint、事件 receipt hash，并有 canonical record hash。
- `ReplayWriterV2` 独占创建、逐行 flush、严格 tick；`ReplayReaderV2` 校验全部外锚、序列和记录哈希。
- V2 Replay 模块不导入 Session、World、dynamics 或 RNG；回放只重建 immutable frame index。
- live 与 replay 使用同一个 Frame DTO；读取/渲染不推进 Session tick。
