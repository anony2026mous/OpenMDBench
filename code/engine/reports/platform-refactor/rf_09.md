# RF-09 阶段报告：Capability 子系统与固定 Tick 接线

## 阶段结论

- 状态：PASS；RF-10 ALLOWED。
- RF-09 新增 capability 子系统契约 4/4；Combat/World/Session/Checkpoint 联合 253/253。
- Ruff、格式、strict mypy、compileall 与 diff-check 通过。

## 交付能力

- 新增通用 `GenericSubsystemEngineV2`，只消费 immutable entity/resource facts。
- sensor 使用每 owner/sensor/target 命名 RNG 子流；实体和注册顺序不影响 receipt。
- energy 只消费 Resolved 显式 rate 参数；缺参数保持零消耗，不按平台类型猜公式。
- communications 由 capability endpoint 驱动；`send_message` 已形成 Session typed intent→World 通信阶段→权威队列 receipt，并保持 exactly-once。
- World tick 顺序扩展为 lifecycle→dynamics/boundary→energy→sensing→communications→combat→damage→mission→scoring→cooldown。
- subsystem receipt 进入 World tick ledger 和 checkpoint，恢复后结构等价。
- World 生成 faction ObservationV2；仅公开己方实体和 opaque contact，不暴露 target truth，读取不推进 tick。
- 任一子系统异常与 World tick 一起回滚 entity energy、contact、message、adapter 和所有既有 ledger。
