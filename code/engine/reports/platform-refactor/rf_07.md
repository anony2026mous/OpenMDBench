## 交付能力

- Scenario Compiler、Resolved、World、MissionEngine 与 ScoringSystem 形成真实端到端运行链路。
- 14 类 typed condition operator 与递归 all/any/not；缺失端点、DAG、深度和类型均 fail closed。
- World-owned immutable Mission facts，覆盖 entity lifecycle、platform/domain/controller、direct/dependency capability、contact、resource、wave、zone membership/activation 与 swept enter/leave。
- Runtime selector 支持 future spawn、active、destroyed、despawned；已消费 lifecycle blueprint 不会重新成为 scheduled。
- Typed terminal outcome、priority/tie-break、ranking、exact event evidence、一次锁存与幂等 receipt。
- Scoring 支持每 metric 独立 aggregation/direction，以及显式场景总策略；严格区分 N/A 与 zero、competition score 与 training reward。
- Event accumulator 仅消费 World typed event receipt，并按 Resolved event source/value path/unit 策略提取；事件 ID 去重。
- Trusted mission/scoring plugin 与 Resolved/Registry artifact、interface、unit、metric 精确绑定；fresh session instance、checkpoint 与确定性 replay。
- Mission/Scoring 作为统一 World tick 的真实阶段，任一 rule/metric/plugin 失败会回滚 World、ledger、terminal、accumulator 与 plugin state。
- Checkpoint 对 rule、terminal、metric、score、plugin 与 event inputs 执行 Resolved-aware 语义重建；内外层协调重哈希攻击稳定拒绝。
