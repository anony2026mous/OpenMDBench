## 契约

- Catalog v2 统一管理 17 类资源、精确版本引用、引擎兼容、依赖与内容哈希。
- ModelRegistry v2 冻结可信、确定、隔离安全的模型工厂及 artifact 身份。
- Catalog 与 Registry 构造完成后不可重绑定，Catalog hash 同时绑定 Registry hash。
- 模型 metadata 约束可服务资源类型、输入输出 Schema 和字段单位。
- `validate_full_composition()` 原子校验平台、动力学、挂载、传感器、通信、能源、碰撞、可视化、弹药、武器、Effect 与 DamageModel 完整闭链。

- 武器库存到 Loadout 弹药引用采用确定性一对一映射；缺失、歧义或不兼容时 fail closed。
- 零弹药库存仍校验 Loadout 全部武器的平台、目标域、Effect 和 DamageModel。
- 通用组合编译只依赖 CatalogV2/ModelRegistryV2；旧 Catalog 加载隔离在显式 Legacy 适配模块。
