- Ruff、格式、strict mypy 与 diff-check 通过。

## 交付能力

- `AgentGatewayV2` 是唯一 transport-independent authority；只暴露 Session CRUD/control、Observation、Action submit/status、events/result、step、checkpoint、visualization 和 replay artifact。
- `StructuredPythonAdapterV2`、`GymnasiumAdapterV2`、`VectorEnvAdapterV2` 全部委托同一 Gateway，不读取 WorldState。
- Gym 保持标准 reset/step 五元组；Vector 强制非空、唯一 session 与动作 cardinality。
- REST `/v2` 提供 session create/list/control/delete/restore、observation、actions/status、events/result、step、checkpoint、visualization 和 replay artifact；schema extra-forbid。
- REST restore 由服务端注入显式 Resolved/Registry/World 恢复工厂，Gateway 再次精确比对 session ID 与 checkpoint hash，不信任运输层自证。
- REST 使用 async endpoint，避免把 native session writer 隐式迁移到线程池。
- Python/Gym 对同 seed 和动作时间线产生等价公开 Observation；REST retry 返回同一 action receipt，fire 只消费一次。
- Vector 多 session 独立推进并显式 close；跨 session ID/action route 不匹配稳定拒绝。

## 通用性与安全

- Adapter 不实现 dynamics、boundary、combat、mission 或 visibility 规则。
- Observation 由 World faction snapshot 统一生成；REST/Gym 不获得 referee truth 或 mutable World。
