## 交付能力

- `WorldFactoryV2` / `EntityFactoryV2` 从 `ResolvedScenarioV2` 构造任意阵营、任意数量实体，不依赖场景 ID、固定阵营或固定实体类型。
- 定义与运行态隔离；公开实体仅提供不可变视图，权威状态只能通过事务入口修改。
- exact-model native dynamics：UAV、AUV、fixed 与显式 MMG worker 协议；MMG worker 不可用时 fail closed。
- native artifact 使用实际源码或 worker bytes 摘要，并在 Registry 建立后、World materialize 前再次验证漂移。
- typed capability token、direct/dependency 区分、exact all/any 查询和不可变索引。
- controller slot/controller/entity 双向 ownership，逐实体 capability evidence、exclusive claim、uncontrolled policy 与 spawn reservation。
- lifecycle CAS、幂等 operation ledger、同 tick 原子 spawn/despawn、永久 used-ID、tombstone、RNG/索引回滚及真实 adapter cleanup audit。
- `WorldCheckpointV2` canonical JSON/hash、外部 checkpoint/Resolved/Catalog/Registry 锚、native snapshot 完整闭包、N+M 确定性恢复和源 World 隔离。
- checkpoint restore 对 initial 与 replacement adapters 使用统一 staging ledger；失败逆序清理，成功替换后的旧 adapter close 错误也进入不可变审计。
