## 交付能力

- 六态 Session 状态机与 Session 单写入者；公开面仅提供只读 World/Queue/Status view。
- Action submit 只入队；batch、operation、child ID 全会话幂等与冲突检测。
- persistent navigation/hold、discrete fire 的 typed World 派发；未接线动作在 submit 原子 fail closed。
- apply-time controller、faction、lifecycle、capability 与 payload 复验；TTL 到期使用显式 safe-hold。
- Session checkpoint 保存 World、pending/active/consumed、batch/child/apply ledger 与完整外锚。
- `LockstepRunnerV2` 按 decision interval 精确推进；`ContinuousRunnerV2` 只有一个后台写线程；1x/10x/unbounded 只影响 wall pacing。
- `ReplayRunnerV2` 只读不可变记录，不持有 Session 或 World。
- pause/resume/terminate 与 tick writer 线性化；GET/view 不推进逻辑时钟。
