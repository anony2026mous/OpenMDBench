## IMPLEMENTATION_AND_EVIDENCE

- `openmdbench/systems/generic_v2.py` 只在 Catalog 有显式 `altitude_range_profile` 时启用 AGL 门：`reference=agl`、`transition=step`、`target_agl <= ceiling` 进入低空 range。profile 缺少目标地表/海面高度时抛出稳定的失败，不会把 local Z、MSL 或相对传感器高度当作 AGL。
- 量程顺序为：先用 profile 选择原始低空/名义 range，再按已经解析的名义量程倍率缩放。因此现有 `sensor.range` 环境 modifier 在高度选择后生效。距离门失败的 receipt 的 `sample` 为 `None`，没有概率或测量 RNG 样本；receipt 记录 `target_agl_m`、`altitude_range_reference` 和实际 `sensor_range_m`。
- `openmdbench/world/geography_v2.py` 增加 `GeographyServiceV2.surface_elevation_m`。它仅消费 map resource 中显式的 `{reference: local_sea_level, elevation_m: ...}`；无声明时产生 `geography.surface_elevation_unavailable`，由无 profile 的旧传感器保持原名义量程行为，而 AGL profile 失败关闭。
- `openmdbench/world/factory_v2.py` 让每个 subsystem fact 带入上述 geography 结果，并在 lifecycle rebuild/restore 时从同一 resolved artifact 重建 geography；checkpoint 继续保存含 AGL 字段的 subsystem receipt。
- `catalog/v2/md_ad_002.yaml` 保留 `2.0.0`/`2.1.0` 历史资源，新增 shore/picket 的 `2.0.1` 与 `2.1.1`，以及 `map.weihai-local@2.1.0`。所有新的 300 m 和量程参数均附 `UNVALIDATED_BENCHMARK` 注释。easy/hard 保留原 `2.0.0` 概率/噪声语义而升级到 `2.0.1`；medium 保留原 `2.1.0` 概率/噪声语义而升级到 `2.1.1`。三个正式场景均显式使用 map `2.1.0`。
