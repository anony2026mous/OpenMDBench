### 1.1 `openmd/code/.env` 的实际内容（打码）

```
OPENAI_BASE_URL = http://…（25 字符）
OPENAI_API_KEY = EMPTY
LLM_DEFAULT_MODEL = DeepSeek…（28 字符）
# Previous (slow reasoning model, ~2min/call):
# OPENAI_BASE_URL=http://172.18.116.175:10000/v1
# OPENAI_API_KEY=pk-19b36d…（32 字符，完整有效）
# LLM_DEFAULT_MODEL=Qwen3.5-122B-A10B-FP8
```

**要点**：

- 被注释的那行里是一个**完整未打码的 key**，并附带内网端点。
- 该文件**未被 git 跟踪**，且 huairou 同步默认排除 `.env`（已在服务器确认不存在），所以**没有外泄到服务器**。
- 但**建议轮换这个 key**——它在本机以明文存在，且本次会话中曾被读取。
- 同目录的 `openmd/code/.env.example` 内容是 `localhost` + `EMPTY`，**可以保留**。

### 1.2 顺带发现的一个 `.gitignore` 缺陷

`.env.example` 里写着「code/.env is git-ignored and must never be committed」，
但根 `.gitignore` **并没有这条规则**（当前只有 `.huairou/` 与 `tools/huairou/__pycache__/`）。
建议补上：

```gitignore
.env
!.env.example
openmd/code/.env
```
