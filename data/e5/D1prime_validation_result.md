# D1′ 先验刻画验证：结果与限制（诚实版）

> 目的：清单 §1.2 要求"计算每个场景的 D1′ 先验得分与该场景**实际分层优势**的相关性，
> Spearman ρ > 0.5（p < 0.05）则 D1′ 先验刻画成立"。
> 本文记录**两次尝试**、各自的方法学限制，以及能支持与不能支持的结论。

## 1. 观测量的定义

**分层优势** = LLM+stack composite − best pure baseline composite
= `layered_metrics.performance_v(ie_llm_*) − max(performance_v(ie_rule_*), performance_v(ie_purellm_*))`

数据源：`openmd/code/eval/_w1_runs/`（本地四臂归档，无需新跑实验）。
D1′ 先验分：`d1prime_FROZEN.json`（本角色独立标注，只读设计文档，44/55 场景）。

## 2. 尝试 A：同配置 tag 严格配对（7 个场景，**唯一可用于结论的版本**）

|---|---|---|---|---|---|
| IE-06-DECOY-MIXED | 0.8444 | 0.8711 | 0.8044 | **+0.0267** | 2.50 |
| IE-07-CROSS-DOMAIN | 0.8233 | 0.7933 | 0.7800 | **−0.0300** | 2.17 |

**为什么这一版不能用**：各臂文件名带的是**不同开发轮次的配置标签**（rule 侧 `_p18`/`_renum`，

IE-08 的 −0.7301、IE-01 的 −0.1000 都明显是配置错配的产物（rule 侧新、llm 侧旧）。
放在这里是为了**留痕**：如果有人日后算 ρ，不能走这条路。

## 4. 能支持与不能支持的结论

**能支持的（数据直接给出）**：

1. **7 个可严格配对的场景里，D1′ 先验分与观测分层优势无相关**（ρ = −0.0092，p = 0.9972）。
   即：按现行 6 维先验分，**无法预测**哪个场景的 LLM+stack 会优于最强纯基线。
2. 分层优势本身**极小**：7 个场景的取值范围只有 [−0.0300, +0.0858]，其中 2 个恰好 0.0000。
   也就是说这些场景上"LLM 叠层"与"最强纯基线"的差距接近噪声水平。
3. 先验分与分层优势的**序关系不一致**：先验最高（2.50）的 IE-06 只有 +0.0267，
   而先验仅 1.83 的 IE-05 拿到最大 +0.0858；先验 2.17 的 IE-07 是负值。

**不能支持的（必须说明，否则会误导）**：

1. **样本量与量程都太小**：7 个场景、因变量量程仅 0.116。
   量程受限（range restriction）会系统性压低相关系数，**因此这个 ρ 既不能证明"先验无效"，
   也不能证明"定律不成立"**——它只能说明"在这 7 个场景上测不出预测力"。
2. 观测分层优势的**测量口径不唯一**：本文用 `layered_metrics.performance_v`，
   而 `three_arm_table.md`（MD-AD-006 单场景）用的是另一套加权 overall（rule 0.532 /
   hybrid 0.630 / pure 0.527）。两套口径不宜混用，需主理人指定。
3. **不是同一批次**：7 个场景的 run 来自不同开发轮次（虽 tag 相同），
   严格做法应由主理人用同一冻结版本重跑三臂。

## 5. 建议（交主理人决策）

1. **指定唯一口径**：分层优势到底用 `performance_v` 还是三臂表的加权 overall。
2. **重跑一次受控三臂**：同一冻结版本、同一 tag、14 个 IE 场景 × 3 臂，
   才能得到可用于论文 §7 的 ρ（预计是 local grid 任务，不占用 LLM 服务除外）。
3. **扩大因变量量程**：当前 7 个场景的分层优势几乎全在 ±0.03 内，
   即便有真效应也测不出来。可优先选 D1′ 先验分跨度大的场景（如 IE-06 = 2.50 与 IE-03 = 1.17）
   并确保场景本身有 headroom（这正是 D2 重标定在做的事）。
4. **若最终 ρ 仍不显著**，按项目"如实报告"原则，应把 D1′ 从"预测性定律条件"
   降级为"事后描述性刻画"，并据此调整论文 §3 的措辞。
