# E14 Grid complex 基线强度诊断：实验设计 v1

依据：2026-10-03 14:39 v9强化清单§3。任务目标是排查原complex层pure MAPPO 0%是否反映训练不足，而不是以得到预定方向为验收条件。实际实验只在远程进行，不修改论文、引擎、场景文件、reward或原主实验数据。

## 1. 资产前置审计与适用范围

当前远程Git工程未带旧Grid训练日志或complex checkpoint；唯一可用权重为已从原实验包补入的 `mappo_medium_s42_best.pt`（82维actor、128维critic，元数据开发SR=1.0）。不能从文件缺失推断原训练未收敛，也不能把该权重的历史元数据当成当前seed表现。

因此按清单的“历史日志缺失则从步骤2开始”规则，开展当前冻结源码上的独立诊断重训。先用现有medium权重在simple/medium/complex各10个新评估seed核查迁移表现，再记录12次训练的完整在线曲线。

原稿提到过complex20M和curriculum，但其原曲线/权重未交付。下面10M预算只是当前源码默认5M的×2，并非旧20M训练的×2；当前负向结果不能替旧历史证据背书。找到正向改进也不能自动证明旧实验实现错误，需比较原checkpoint与协议。

## 2. 冻结实验矩阵

训练seed：22001、22002、22003。四配置各3次训练，共12次，12路并发，各Python/Torch/BLAS单线程；总75M环境步预算。

|配置|初始化|预算|学习率|entropy coefficient|用途|
|---|---|---:|---:|---:|---|
|default_extended|随机|10M|3e-4|0.01|原默认超参延长至当前默认预算2倍|
|medium_curriculum|现有medium权重|5M|3e-4|0.01|检查medium→complex迁移是否改善|
|lr_half|随机|5M|1.5e-4|0.01|学习率减半扫描|
|lr_double_entropy_double|随机|5M|6e-4|0.02|学习率及熵系数翻倍扫描|

后两组为清单所要求的2组超参扫描。最后一组同时改变两项，只判断组合是否改善，不分离学习率与熵的独立效应。

沿用原MAPPOTrainer：连续授权模式、goal训练注入概率0.5、每20步注入、8env、4096步rollout、4轮PPO、batch512、gamma0.99、GAE0.95、clip0.2、value coefficient0.5、梯度裁剪0.5。确认推理采用纯actor argmax，无上层goal，不调用LLM。不是把遗留的轻量PureRLAgent误当成MAPPO。

课程初始化仅加载actor/critic权重，Adam、reward-normalizer、步数从零开始，不称精确续训。所有配置完整写入manifest和每seed独立config。

## 3. 指标与防止确认集选模

开发评估固定10seed：23101–23110，每100k步记录SR、raw reward、局长；best只按开发SR严格更高才更新。最终同时评价预先声明的best和final，确认seed固定24101–24110，绝不按确认结果选更好的checkpoint。

每个checkpoint以10个环境seed评估，跨配置重复seed是本诊断批次内部比较；跨独立训练seed的总体SR及20,000次bootstrap CI以训练seed为单位，n=3，不把30条评估轨迹冒充30个独立训练重复。所有配置方向和best/final均保留。

每rollout额外记录原始reward分布、非终局正reward数量、训练完成局数及SR、归一化return、policy/value loss、entropy；据此可算最后10%训练窗口按完成局数加权的SR。记录器仅在原reward计算之后读取返回值，不改变计算、参数或RNG。

512步原生与记录版rollout/更新必须动作、奖励、观测、优势、loss和更新后actor逐项相同后才允许启动正式诊断。单个训练墙钟上限24小时，超时、部分曲线和权重保留，不覆盖或删除失败。

远程现有Torch为CPU-only，不能使用两张闲置GPU；不擅自升级CUDA Torch或扰动vLLM环境。CPU并行仍利用容器资源。

## 4. 预先固定的判断

- 任何确认成功均记录；配置均值SR>20%作为需要通知主理人的诊断改善触发量，不称已完成原论文主表修正。
- 有改善：报告受测配置能学习/原0%不是普遍能力上限的线索，建议主理人核对旧权重后批准新主实验；不静默替换数据，不自动重跑六臂或tournament。
- 无改善：只称这些配置及有限预算下未改善，不能证明任务数学意义上不可学。曲线仍上升也不得宣称收敛。
- 结构分析保留三档真实参数：地图20×20、时间150步相同，复杂度差异来自目标/波次/异常/执行噪声/丢包/UAV追击等。reward并非只有终局奖励；Categorical熵探索也没有epsilon调度。
- 简化complex涉及冻结场景参数改动，本轮不实施；需要用户另行明确授权后独立冻结，不能凭清单建议自行修改引擎或拿新场景替换旧数据。
