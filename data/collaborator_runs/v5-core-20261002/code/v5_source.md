## 1. E10-高保真：特征域对齐判别重测（P0，最高优先）

**背景**：Grid 侧 E10 已完成（rule 仅 64 格网格 76.25%/83.75% vs LLM 78.25%/82%，Cinfo≈0，D1 未通过）。高保真是决定路径 A/B 的关键一测。

**设计**：
- **rule 判别器**：真实连续观测通道的**受限版本**（先明确通道对应再设计，**不虚构网格接口**）→ 期望 ≤60%。
- **LLM 判别器**：简报文本（语义通道真实输入，8 次接触序列文本 + 态势信息，匿名化处理同 pilot）→ 期望 ≥85%。
- 刺激集：**冻结 400 事件正式协议**（IE-06、IE-11 各 400，每类 200）。
- 数值与 LLM 判别**必须在同一冻结刺激集、同一统计单位**上对照（报告 §4 强调）。

**协议**：200 正例 + 200 负例，二分类；报告平衡准确率 + ROC-AUC + 95% CI（bootstrap）；规则判别器特征集限定（记录特征清单）；LLM 输入记录完整 prompt 模板。**明确限定"受控刺激集判别成绩，非在线自主识别率"**（附录 G 口径不变）。工程门：解析错误 ≤5%、空响应 ≤5%（沿用 §6.7）。

**通道对应前置问题（须先解决再跑）**：高保真真实执行器为**连续观测**——数值判别器应喂什么、取什么窗口/降采样，须先明确与执行器实际可观测状态对齐，不造出不存在的接口。这一设计决策请记录并反馈。

**成功判据与分支**：
- **路径 A**：rule ≤60% 且 LLM ≥85% → 信息不对称在正区成立、Grid 边界区不成立；定律保留三条件，改动小。
- **路径 B**：任一不满足 → Cinfo 从定律降格为报告量，条件(i)重构为"接口信息因果必要"（goal-dose 证据）；正区胜因归因决策形态（D1′）。§3.3/§6.7/附录 G/Fig.1 均需改（论文侧由主理人负责）。

**产出**：附录 G 判别协议正式版（特征清单 + prompt 模板 + ROC）；§6.7 D1 门改实测值；Cinfo 连续测量进 §6.8。**结果回传时请附**：完整平衡准确率、AUC、seed 聚类 CI、配对 Cinfo 差、ROC CSV、模型与逐事件预测、manifest 哈希、prompt 模板（对齐 E10-Grid 的交付标准）。

**不越界**：不因缩窄特征而宣称 D1 通过；阈值 60/85 不动；不选有利子集；如实报告失败（路径 B 是可辩护的诚实结局，不要为过门改口径）。

## 2. E1：headroom 受控操纵实验（P0）

**目标**：把定律第三条件（`headroom(V_m) > 0`）从"观测趋势"升级为"受控因果验证"（补 R1/R2）。

**当前缺口**：附录 A 只有 14 个已入场场景的 Spearman 相关（ρ=−0.50/−0.68，混杂场景差异）；没有在同一场景族内主动操纵基线强度。

**设计**：取 **IE-05 Multi-axis（基线中强）与 IE-09 Staggered waves** 两个已入场场景作为载体，用对手强度旋钮（附录 C：波次节奏、诱饵比例、护航数）把**最好纯基线 SR 操纵到 40% / 60% / 80% 三档**（D2 操作窗口内），每档跑 10 paired seeds，测分层栈（LLM+Rule 与 LLM+RL）相对该基线的 ΔV。

**协议**：
- 每场景 × 3 档 × 10 seeds × 3 栈（best-pure、LLM+Rule、LLM+RL）= 270 episodes；基线档位用旋钮在冻结引擎上标定（SR 落在 ±3pt 内才算合格档）。
- 统计：seed-bootstrap 95% CI，ΔV 对 headroom 档的秩相关 + 单调性检验；与附录 A 的 Spearman 对齐口径。
- 门：LLM 栈沿用 no-intelligence prompt regime；executor 用 rule（LLM+Rule）与 MAPPO 单锁 checkpoint（LLM+RL）。

**成功判据**：ΔV 随 headroom 档单调递增（至少秩单调，2/3 档显著）；档间 ΔV 差异的 95% CI 不含 0。若 40% 档（高 headroom）ΔV 显著为正、80% 档（低 headroom）ΔV ≤ 0，即为定律第三条件的直接因果证据。

**产出**：论文 §6.8 或附录 A 新增"headroom 操纵"表/图（ΔV vs headroom 三档，两场景各一列）。

## 3. E2：剂量–增益形状（P0，f 的代理形状）

**目标**：让 Eq.(4) 从"示意式"变成"有数据支撑方向性形状的定律"（补 R1）。

**设计（数据复用为主，少量补跑）**：
- 复用 **P2 goal-dose 批次（seeds 512–521）** 已有的 4 个剂量点：hold / mask2 / mask1 / strong（界面携带量 0→低→中→高，正文 §5.2）。
- 复用 **P1 六臂批次（seeds 501–510）** 的 ΔV_A/ΔV_B 与 ΔI。
- 补跑（仅当需要第 5 个点）：一个"增强剂量"档（goal 内联完整态势文本 vs 当前目标摘要），~20 局（2 栈 × 10 seeds），确认形状右端。

**协议**：以"被掩蔽单位数/轮"作为 Bif 的序数剂量轴（明确标注：单位可用性水平，非 bits）；以 strong−hold 区间内 ΔV 相对值作增益轴；报告 4–5 点上的均值与 CI，标注非单调区（现有数据已显示 mask1 处非单调：rule 0.833 vs strong 0.670）。

**成功判据**：给出剂量–增益曲线的完整图（hold 处 ΔV=0 锚点 → strong 处 ΔV=+0.457/+0.537），并显式报告"非单调区存在于 mask1"——把"更多信息总是更好"的证伪做成图，而非只写一句话。

**产出**：论文 §6.4 新增"剂量–增益"子图（或在 Fig.1 右下 Test 1B 区加小面板）；正文 Eq.(4) 下方补一句"f 的方向性由剂量–增益曲线支持（非单调于 mask1 处）"。

## 4. 执行约束（与正文/附录保持一致）

1. **批次独立**：每个实验一个独立批次，seeds 不跨批次复用；与既有批次**禁止拼接统计**（正文 §6.4 限定）。
2. **统计口径**：seed 为抽样单位；seed-bootstrap 95% CI；无 tick 级伪重复（附录 F）。
3. **manifest 冻结**：每个新批次的引擎与场景版本 SHA-256 冻结；LLM 用单一锁 checkpoint（附录 F/J）。
4. **不可越界**：剂量仍为"单位可用性水平"非 bits；不拟合 f 的解析形式（E2 只报告方向性形状）；不宣称在线自主诱饵识别率（附录 G 限定）；判别成绩限定为受控刺激集；不碰 D1 阈值。
5. **失败如实报告**：任一实验未达成功判据，如实写进论文——这些本身都是可发表的定律边界证据——不要为叙事强行改判据。
